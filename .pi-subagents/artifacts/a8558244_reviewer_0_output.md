## Review

- **High — unsupported plugin mode remains selectable:** `ui/src/lib/stores/engine.svelte.ts:301-306` adds `ExplicitIntervals` globally, but `ui/src/lib/components/PluginWorkspace.svelte:39-41`, `CompanionPanel.svelte:22-25`, and `VoicesPanel.svelte:107` do not filter it using `intervalMaps`. The plugin declares it unsupported at `ui/src/lib/adapter/plugin.ts:75,223-225`; selecting it can leave UI state claiming a mode whose map cannot be configured. Apply is correctly blocked, but manual selectors must also be gated.
- **Medium — routing is calculated before octave transformations:** `crates/contrapunk-harmony/src/engine.rs:1211-1219` assigns arrangement indices, then `apply_octave_mode` can reorder pitches (`:1020-1027`). For source 60, offsets `[12,7]`, three voices, and full Spread, final harmonies become 84 and 91 while 84 retains slot 0. This violates the final-pitch-order requirement at `.planning/phases/10.2-arrangement-presets/research/01-cloister-organum/synthesis.md:69`. Recompute routing after octave processing and add a non-`None` octave test.
- **Medium — edited maps do not reach WASM Companion mini-engines:** `ui/src/lib/adapter/wasm.ts:524-531` updates only the primary engine, while its companion synchronization at `:390-405` has no interval-map field. `crates/contrapunk-companion/src/canon_lane.rs:503-508,546-548` reads the map from the Companion snapshot. Consequently, WASM canon voices using `ExplicitIntervals` retain default fifths after edits, unlike Tauri. Extend the WASM companion bridge and test a custom-map canon voice.

### Residual risks

- Balanced releases are tested sequentially only. Overlapping sources that generate the same pitch remain untested; Cloister’s performer contract explicitly discourages overlap.
- Generated WASM bindings contain the new export and source builds pass, but artifact reproducibility was not verified by regenerating the binary.
- No browser-level test exercises Apply → manual edit → Save As → reapply; current tests verify catalog validation and serialized persistence separately.
