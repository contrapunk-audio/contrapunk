I recently tested the Contrapunk presets.
Here is my honest review of the sounds:

Cloister Organum: This sounds like a really old organ sample, and it is actually nice.

Modal Linework: This is a very clean and modern kind of preset.

Mensuration Web: It is similar to Modal Linework, but it has a slightly different texture.

Stretto Engine: Another preset with a plucky kind of sound. It sounds like it has been stuffed with filters. It is nice.

Suspension Garland: This one is my favorite preset. It has a very modern organ sound, and it is really good.

Planed Cathedral: This is similar to Suspension Garland, but it sounds like it is a little muddy {in a good way}.

Color Mode Windows: This is another nice preset with a modern sound and a rich texture.

Sixeth Diminished Conveyor: It does sound like a 6th diminished chord, but I do not like this a lot.

Bebop Chase: This is another one of my favorites. It has a great plucky texture.

Quartal Colosuss: This sounds like pads from the 2010s, and it has got a really good texture.

Hollow Choir: This is a really bassy pad. It has got crunch.

Pixel Trio: This preset is broken. It is not available to play and needs to be fixed.

Crystal Chorale: This sounds like a cloudy pad. It is not good according to me. A little distortion might fix it.
