Current features enabled: Window, Navigator, MidiAccess, MidiOptions, MidiInput, MidiOutput, MidiPort, MidiMessageEvent. The `.inputs()` and `.outputs()` methods may need `MidiInputMap`/`MidiOutputMap` features — check what web-sys actually provides by searching the web-sys docs or source. Alternatively, the methods may need different feature names.

   Approach options:
   a) Find the correct web-sys features for MidiAccess.inputs()/outputs()
   b) If features don't exist, rewrite web.rs to use js_sys::Reflect to access properties
   c) Skip web.rs entirely — the WASM adapter in TypeScript already handles Web MIDI via the JS API directly. Could gate out web.rs from the WASM build since it's redundant with the TS adapter.

   **Option (c) is likely simplest** — the contrapunk-wasm crate only needs the harmony Engine, not MIDI I/O. The TypeScript WasmAdapter already handles Web MIDI.
