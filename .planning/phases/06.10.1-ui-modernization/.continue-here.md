<decisions_made>

- Gate `web.rs` behind feature flag instead of target_arch: the contrapunk-wasm crate only needs HarmonyEngine, not Rust-side MIDI I/O
- Made web-sys/wasm-bindgen/js-sys optional deps behind `web-midi` feature in root Cargo.toml
- Disabled wasm-opt: bundled version doesn't support bulk memory ops emitted by modern Rust
- WASM Engine defaults to 4 voices (SATB) via `with_voices()` instead of 2
- Voice count is engine-internal, not derived from output port count
- Output routing wraps: `resultNotes[i] → outputs[i % outputs.length]` when fewer outputs than voices
- Preset save creates custom presets with empty persona and "Custom" genre
- Init gate: content area only renders after adapter.init() completes (prevents race conditions)
</decisions_made>
