## Decisions Made
- Used a lightweight canvas particle system instead of @tsparticles/svelte to avoid adding two npm dependencies for a simple 30-particle animation
- Placed BeatIndicator inside StatusBar rather than as a separate row, keeping the layout compact and the beat pips near the transport controls
- FX toggle persists to localStorage under 'contrapunk-fx' key; restored on mount in StatusBar's $effect
- GlowEffects component uses `display: contents` to avoid introducing wrapper div layout interference; CSS classes can also be used directly without the component
- Music-reactive vignette uses `$derived` from engine note arrays for reactive state without polling
