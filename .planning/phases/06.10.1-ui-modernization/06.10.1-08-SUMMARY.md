## Decisions Made
- Import WASM module from `$lib/wasm-pkg` instead of external `contrapunk-wasm` package, leveraging SvelteKit's path aliases for cleaner resolution
- Created `build-wasm.sh` helper script that gracefully falls back to a JavaScript stub when wasm-pack is not installed, enabling development without the full Rust toolchain
- Docker multi-stage build runs wasm-pack in Rust container, copies output to Node container for SvelteKit build, serves from nginx alpine
- Changed fly.toml to use `dockerfile = "deploy/Dockerfile"` and deploy from repo root with `flyctl deploy -c deploy/fly.toml` for correct build context
- Increased Fly.io VM memory from 256mb to 512mb to handle the larger SvelteKit + WASM payload
