Update deployment and CI for the new SvelteKit + WASM architecture:

**deploy/Dockerfile:**
Replace the existing Trunk-based build with SvelteKit + wasm-pack:

```dockerfile
# Stage 1: Build WASM
FROM rust:1.82 AS wasm-builder
RUN cargo install wasm-pack
WORKDIR /app
COPY Cargo.toml Cargo.lock ./
COPY src/ src/
COPY wasm/ wasm/
RUN wasm-pack build wasm/ --target web --out-dir /app/ui/src/lib/wasm-pkg --release

# Stage 2: Build frontend
FROM node:22 AS frontend-builder
WORKDIR /app/ui
COPY ui/package.json ui/package-lock.json ./
RUN npm ci
COPY ui/ .
COPY --from=wasm-builder /app/ui/src/lib/wasm-pkg src/lib/wasm-pkg/
RUN npm run build

# Stage 3: Serve
FROM nginx:alpine
COPY deploy/nginx.conf /etc/nginx/conf.d/default.conf
COPY --from=frontend-builder /app/ui/build /usr/share/nginx/html
EXPOSE 8080
```

**deploy/nginx.conf:**
- Update root to `/usr/share/nginx/html` (SvelteKit build output)

- Enable gzip for JS, CSS, WASM
- Cache headers for static assets
- Listen on port 8080 (matching fly.toml)
