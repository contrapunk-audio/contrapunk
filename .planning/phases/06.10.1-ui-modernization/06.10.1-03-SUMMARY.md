## Decisions Made
- Externalized contrapunk-wasm in Vite's rollup and SSR config because the WASM package is built by wasm-pack at deploy time, not available as an npm package during development builds
- Used string-based API in the WASM bridge (e.g. set_key("C")) rather than numeric enums, matching the existing WasmAdapter expectations
- WASM Engine tracks last_input_notes and last_harmony_notes internally since there is no router thread in browser mode
- Svelte 5 stores use optimistic updates (set local state first, call adapter, revert on error) for responsive UI
