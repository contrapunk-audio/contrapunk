- build.beforeDevCommand: "cd ../ui && npm run dev"

**src-tauri/capabilities/default.json:**
- Tauri v2 ACL permissions: allow core:default, core:event:default

**src-tauri/src/state.rs:**
- Define `AppState` struct holding: `engine: Mutex<HarmonyEngine>`, `humanize_config: Mutex<HumanizeConfig>`, `preset_manager: Mutex<PresetManager>`, `is_running: AtomicBool`, `input_notes: Mutex<HashSet<u8>>`, `harmony_notes: Mutex<HashSet<u8>>`, `borrowed_notes: Mutex<HashSet<u8>>`, `chord_name: Mutex<String>`
- Implement `Default` for AppState with sensible defaults (Key::C, PassThrough mode, etc.)

**src-tauri/src/commands/harmony.rs** — Tauri commands:
- `get_engine_state()` -> returns JSON with key, mode, scale_mode, octave_mode, voice_leading_enabled, voice_leading_style, interchange_enabled, interchange_range, voice_position
- `set_key(key: String)` — parse and set key
- `set_mode(mode: String)` — parse and set harmony mode
- `set_scale_mode(mode: String)` — parse and set scale mode
- `set_octave_mode(mode: String)` — parse and set octave mode
- `set_voice_leading(enabled: bool, style: String)` — configure voice leading
- `set_interchange(enabled: bool, range: u8)` — configure modal interchange
- `set_voice_position(position: usize)` — set voice position

**src-tauri/src/commands/midi.rs** — Tauri commands:
- `list_midi_inputs()` -> Vec of device info objects
- `list_midi_outputs()` -> Vec of device info objects
- `refresh_midi_devices()` — re-enumerate

**src-tauri/src/commands/engine.rs** — Tauri commands:
- `start_routing(input_idx: usize, output_indices: Vec<usize>)` — spawn router thread (reuse existing spawn_gui_router pattern from router.rs). Emit "note-update" events via app_handle.emit() when note state changes.
- `stop_routing()` — signal router thread to stop
- `get_note_state()` -> returns current input_notes, harmony_notes, borrowed_notes, chord_name

**src-tauri/src/commands/presets.rs** — Tauri commands:
- `list_presets()` -> Vec of preset names
- `load_preset(name: String)` — apply preset to engine
- `save_preset(name: String)` — save current config as preset
- `delete_preset(name: String)` — remove custom preset

**src-tauri/src/main.rs:**
- Create Tauri builder, register all commands, manage AppState
- `tauri::Builder::default().manage(AppState::default()).invoke_handler(tauri::generate_handler![...]).run(...)`

For the note-update events: In the engine start_routing command, spawn the router thread similar to the existing `spawn_gui_router`. Use a shared `Arc<Mutex<GUIRouterState>>` (or equivalent) and a timer that emits Tauri events at ~30fps with the current note state. The event payload should be a serializable struct: `{ input_notes: Vec<u8>, harmony_notes: Vec<u8>, borrowed_notes: Vec<u8>, chord_name: String, last_borrowed_from: String }`.

All command handlers use `State<AppState>` from Tauri's managed state system.
