Perform the clean break from old GUI:

**1. Remove egui/eframe from Cargo.toml:**
- Remove `eframe` from `[dependencies]` (including the optional feature)
- Remove the `gui = ["eframe"]` feature flag
- Remove the `wasm = ["gui"]` feature flag
- Keep all non-GUI dependencies (wmidi, rand, serde, serde_json, anyhow, midir, clap, etc.)
- The root crate becomes a pure library + binary (no GUI feature gating)

**2. Remove CLI mode from src/main.rs:**
- Per CONTEXT.md: "Drop CLI mode — desktop app and browser are the only interfaces going forward"
- Remove all `#[cfg(not(feature = "gui"))]` code blocks
- Remove CLI-specific imports (stdin prompts, interactive port selection)
- The binary target in main.rs should now only:
  - Parse CLI args (--server, --client for server mode — keep these, they're useful)
  - If --server: start server mode (existing functionality)
  - If --client: start client mode (existing functionality)
  - Otherwise: print a message directing users to run the Tauri app or open the browser
- Remove `mod app;`, `mod ui;`, `mod piano;`, `mod theme;`, `mod chord;`, `mod preset;`, `mod midi_defaults;` from main.rs (these are GUI modules now handled by Svelte)

**3. Simplify src/lib.rs:**
- Remove the WASM entry point (`#[wasm_bindgen(start)] pub fn main()`) — this was the old Trunk bootstrap
- lib.rs becomes the library entry point for all targets:
  - `pub mod harmony;`
  - `pub mod humanize;`
  - `pub mod generator;`
  - `pub mod midi;` (behind cfg for non-wasm32, or keep accessible)
  - `pub mod chord;`
  - `pub mod preset;`
  - `pub mod router;` (behind cfg for non-wasm32)
  - `pub mod server;` (behind cfg for non-wasm32)
  - `pub mod midi_defaults;`
- Remove `mod app`, `mod ui`, `mod theme`, `mod piano` from lib.rs

**4. Delete old GUI files:**
- Delete `src/app.rs` — ContrapunkApp (egui) is replaced by Svelte
- Delete `src/ui.rs` — egui UI components replaced by Svelte components
- Delete `src/piano.rs` — Piano keyboard now in Svelte
- Delete `src/theme/` directory entirely — Rust theme (colors.rs, widgets.rs, mod.rs) replaced by CSS

**5. Delete old WASM build files:**
- Delete `Trunk.toml` — Trunk is no longer used (replaced by wasm-pack + SvelteKit)
- Delete `index.html` at project root — this was the Trunk canvas entry point

**6. Verify clean compilation:**
- `cargo check` — core library compiles without egui
- `cargo check -p contrapunk-tauri` — Tauri backend compiles
- `cargo check -p contrapunk-wasm` — WASM bridge compiles
- `cargo test` — all harmony/humanize/generator tests still pass
