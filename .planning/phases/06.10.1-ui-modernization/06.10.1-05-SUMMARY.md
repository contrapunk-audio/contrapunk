## Decisions Made
- Used Number.MAX_SAFE_INTEGER as sentinel values for virtual inputs, matching the existing usize::MAX pattern in Rust app.rs
- Output slots use a dynamic array model (filter out invalid entries) rather than a fixed 8-element array, which simplifies the UI logic
- Delete confirmation uses an inline toggle pattern (click shows "?", second click confirms) rather than browser confirm() dialog for better UX
- Preset list capped at 200px max-height with overflow scroll to keep the left column compact
- Fixed Svelte 5 event modifier syntax: replaced `onclick|stopPropagation` pipe syntax (removed in Svelte 5) with inline `e.stopPropagation()` call
