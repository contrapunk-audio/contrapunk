## Decisions Made
- **@sveltejs/vite-plugin-svelte v5.x:** v4.x requires Vite 5, but we use Vite 6. Updated to v5.x which has `peerDependencies: vite@^6.0.0`.
- **prerender handleHttpError: 'warn':** Adapter-static SPA mode generates a fallback index.html; strict prerender errors on missing assets (like favicon before it existed) would block builds unnecessarily.
- **Press Start 2P via Google Fonts CDN:** Kept the existing font choice per CONTEXT.md ("Keep Press Start 2P pixel font or find one that fits the HLD aesthetic better"). CDN link in app.html for simplicity; can self-host later.
- **Inline body background in app.html:** Set `background-color: #0f0e1a` directly on `<body>` in the HTML to prevent flash of white content while CSS loads.
