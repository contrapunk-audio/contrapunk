Create the sacred 88-key piano keyboard as a Svelte 5 component with HLD styling.

Port the layout logic from `src/piano.rs` (PianoKeyboard) to Svelte/CSS:

**Piano.svelte:**
- MIDI range: 21 (A0) to 108 (C8) — 88 keys
- White keys rendered as `<div>` elements in a flex row
- Black keys positioned absolutely relative to the white keys container
- Use `isBlackKey(midi)`: [1,3,6,8,10].includes(midi % 12)
- Each key gets a `data-midi` attribute for identification

**Color-coded keys (SACRED — preserved from CONTEXT.md):**
- Input notes: var(--color-piano-input) green (#00e436)
- Harmony notes: var(--color-piano-harmony) orange (#ff9933)
- Generator-selected: var(--color-piano-generator) magenta (#ff3388)
- Borrowed (interchange): var(--color-piano-borrowed) amber (#ffaa33)
- In-scale: subtle tint var(--color-piano-in-scale) (#1a1844)
- Default white: var(--color-text-primary), default black: #111

**HLD styling:**
- No border-radius (pixel-perfect sharp edges)
- Active keys have neon glow (box-shadow using --glow-* variables)
- Minimal borders between keys (1px --color-border)
- Compact height (adapt to viewport — about 80-100px tall)
- Responsive width (fills bottom of viewport)

**Reactivity:**
- Import engine store: read `engine.inputNotes`, `engine.harmonyNotes`, `engine.borrowedNotes`
- `keyColor(midi)` function returns the appropriate CSS color based on note state
- `keyGlow(midi)` function returns box-shadow for active notes
- Keys should react instantly to note state changes (no transition/animation on key color — per HLD pixel-snap aesthetic)

**Layout:**
- Container uses CSS grid or flex for proper key spacing
- Black keys overlap white keys with negative margin/position
- Use the standard piano key width ratios (white key ~20px wide at 1200px viewport, black keys ~60% of white key width)
- Port the existing `white_key_positions` and `black_key_offsets` logic from piano.rs

**Note display:**
- Show note name (C4, D4, etc.) on keys only when active — small pixel-font label
- Show chord name above the piano (from engine.chordName store)
