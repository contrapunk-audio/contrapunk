## Decisions Made
- HLD health-bar sliders layer a transparent range input (z-index: 2) over a CSS gradient-filled div (z-index: 1) for the neon health-bar look
- Humanize sub-toggles (jitter_enabled, velocity_enabled, etc.) are all linked to the master toggle — when humanize is ON, all sub-effects are enabled; individual sub-toggles can be added later if needed
- Generator uses local state (not yet wired to adapter) since the Rust generator is controlled via the router thread; future integration can connect via adapter
- ActiveNotes sorted low-to-high using $derived reactive blocks for zero-overhead reactivity
- Right column order (ActiveNotes > HumanizePanel > GeneratorPanel) puts the most compact, frequently-changing display at top
