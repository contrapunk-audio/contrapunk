## Decisions Made
- **midi_defaults gated as wasm32+gui**: The midi_defaults module depends on `crate::app` which is WASM-only. On native, the binary's own mod declaration handles it. Gated as `cfg(all(feature = "gui", target_arch = "wasm32"))` in lib.rs.
- **piano gated as gui feature**: piano.rs depends on eframe::egui types, so it stays behind `cfg(feature = "gui")` in the library. The Tauri frontend will have its own piano component.
- **Mutex over RwLock**: Used simple Mutex for all AppState fields. The command handlers hold locks briefly and contention is low (UI-speed operations, not real-time audio path).
- **String-based enum parsing**: Tauri commands accept strings and parse them to Rust enums (accepting PascalCase, snake_case, and numeric formats). This gives the frontend flexibility without coupling to Rust enum serialization.
- **bundle.active=false**: Disabled Tauri bundling during development since proper app icons aren't ready. Placeholder RGBA PNGs created for cargo check.
- **VoiceLeadingStyle::BachChorale**: Corrected from "Bach" to match actual enum variant name.
