  <action>
Create the ui/ directory with a SvelteKit project:

1. Run `npm create svelte@latest ui` — choose Skeleton project, TypeScript, no additional options. If the interactive prompt is not scriptable, manually create the project structure.

2. Install dependencies:
   ```
   cd ui
   npm install
   npm install -D @sveltejs/adapter-static
   npm install -D @tailwindcss/vite tailwindcss
   npm install @tauri-apps/api@^2
   npm install -D vite-plugin-wasm vite-plugin-top-level-await
   ```

3. Configure **svelte.config.js**:
   - Use `@sveltejs/adapter-static` with `fallback: 'index.html'` (SPA mode)
   - Enable vitePreprocess

4. Configure **vite.config.ts**:
   - Plugins: tailwindcss() (from @tailwindcss/vite), sveltekit(), wasm(), topLevelAwait()
   - Order: tailwindcss first, then sveltekit, then wasm plugins

5. Set **ui/src/routes/+layout.ts**:
   - `export const ssr = false;` (required for Tauri compatibility)
   - `export const prerender = true;`

6. Configure **ui/src/app.html**:
   - Standard SvelteKit HTML shell
   - Include Google Fonts link for Press Start 2P: `<link href="https://fonts.googleapis.com/css2?family=Press+Start+2P&display=swap" rel="stylesheet">`
   - Set background color to deep indigo (#0f0e1a) on body to prevent flash of white

7. Configure **ui/src/app.css**:
   - Import Tailwind: `@import "tailwindcss";`
   - Import theme files: `@import "$lib/theme/tokens.css";` and `@import "$lib/theme/pixel.css";`
   - Set global body styles: background var(--color-bg-deep), color var(--color-text-primary), font-family var(--font-pixel), margin 0, overflow hidden

8. Set **ui/src/routes/+layout.svelte**:
   - Import '../app.css'
   - Render `{@render children()}` (Svelte 5 snippet syntax)
   - Full viewport height container

9. Set **ui/src/routes/+page.svelte**:
   - Placeholder content: "Contrapunk" title in magenta, "UI Modernization in progress" subtitle
   - Use HLD colors to verify theme is working

Create the complete Hyper Light Drifter + Ableton-inspired design system:

**ui/src/lib/theme/tokens.css** — CSS custom properties:
- Background layers: --color-bg-deep (#0a0a1a), --color-bg-base (#0f0e1a), --color-bg-panel (#151428), --color-widget-bg (#1a1833), --color-widget-inactive (#25223d)
- HLD accent colors: --color-accent-magenta (#ff3388), --color-accent-magenta-dim (#cc2266), --color-accent-cyan (#33ddff), --color-accent-cyan-dim (#2299cc), --color-accent-teal (#00ccaa), --color-accent-pink (#ff77aa), --color-accent-amber (#ffaa33), --color-accent-gold (#ffdd44)
- Sacred piano key colors (PRESERVED from egui): --color-piano-input (#00e436 green), --color-piano-harmony (#ff9933 orange), --color-piano-generator (#ff3388 magenta), --color-piano-borrowed (#ffaa33 amber), --color-piano-in-scale (#1a1844)
- Text: --color-text-primary (#e8e0f0), --color-text-secondary (#8888aa), --color-text-dim (#555577)
- Borders: --color-border (#2a2848), --color-border-active (#ff3388)
- Glow effects: --glow-magenta, --glow-cyan, --glow-teal (box-shadow values with color spread)
- Typography: --font-pixel ('Press Start 2P', monospace), --font-size-xs through --font-size-xl (8px, 10px, 12px, 16px, 24px)
- Performance toggle: `.reduced-motion` class that sets all glow vars to none and disables animations

**ui/src/lib/theme/pixel.css** — Pixel art rendering rules:
- `.pixel-art, [data-pixel]` — image-rendering: pixelated + crisp-edges fallbacks
- `.font-pixel` — font-family var(--font-pixel), -webkit-font-smoothing: none, -moz-osx-font-smoothing: unset, font-smooth: never, text-rendering: optimizeSpeed
- `.pixel-card` — border-radius: 0 (sharp corners everywhere)
- `.pixel-btn` — base button style with pixel font, instant transitions (transition: none), HLD colors
- `.pixel-btn.active` — magenta background with cyan border and magenta glow
- `@keyframes glow-pulse` — 0%/100% opacity 0.7, 50% opacity 1.0 (3s ease-in-out infinite)
- `.neon-glow` — applies glow-pulse animation
- `@keyframes scan-line` — moving scanline effect (optional, for atmosphere)

**ui/src/lib/theme/colors.ts** — TypeScript color constants:
- Export all HLD palette colors as named constants for use in Svelte components
- Export piano key color mapping function: `getPianoKeyColor(midi: number, inputNotes: number[], harmonyNotes: number[], borrowedNotes: number[]): string`
- Export status colors: running (green), stopped (dim), error (red)

These files directly implement the visual identity described in CONTEXT.md: "Hyper Light Drifter + Ableton Live Session View — a DAW that feels like exploring a neon-lit dungeon." Deep indigo backgrounds with vibrant magenta/teal/cyan/pink neon accents, literal pixel art rendering, blocky fonts, aliased edges.
