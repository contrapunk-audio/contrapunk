Create HLD atmospheric effects using @tsparticles/svelte (or CSS-only fallback if tsparticles integration is complex):

**Particles.svelte** — Ambient background particles:
- Install: `npm install @tsparticles/svelte @tsparticles/slim` (if not already)
- If tsparticles integration proves problematic, implement a lightweight CSS/canvas particle system instead
- Configuration for HLD atmosphere:
  - Low particle count (20-40 particles) — subtle, not overwhelming
  - Particle colors: mix of magenta (#ff338833), cyan (#33ddff33), teal (#00ccaa33) at low opacity
  - Slow drift movement (speed 0.5-1), no gravity
  - Small particle size (1-3px) — pixel-scale dots
  - No interaction (no mouse attraction/repulsion)
  - Positioned as a fixed background layer behind all UI content (z-index: 0)
  - Subtle fade in/out on particles (opacity cycle)
- Render behind the main UI using a fixed position container
- Respect `ui.animationsEnabled` store — when false, render nothing
- Use `{#if ui.animationsEnabled}` guard around the entire component

**GlowEffects.svelte** — Neon glow overlay component:
- A utility component or CSS-only approach for adding neon glow to any element
- Uses CSS box-shadow with color-matched glow values from tokens.css
- Glow pulse animation (glow-pulse keyframe from pixel.css) on active elements
- Can be applied via:
  1. CSS classes: `.glow-magenta`, `.glow-cyan`, `.glow-teal`
  2. Or a wrapper `<GlowEffects color="magenta">` component
- Each glow class adds `box-shadow: var(--glow-{color})` plus the glow-pulse animation
- When `ui.animationsEnabled` is false, glow is still visible (static box-shadow) but does not pulse

**+layout.svelte updates:**

  ```
  </div>
  ```
- Ensure particles don't capture pointer events (pointer-events: none)
