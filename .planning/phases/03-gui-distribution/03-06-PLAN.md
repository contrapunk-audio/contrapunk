<task type="auto">
  <name>Task 1: Configure release profile for optimized binary</name>
  <files>Cargo.toml</files>
  <action>
Add or update the release profile in Cargo.toml for optimized binary size:

1. Add [profile.release] section if not present:
   ```toml
   [profile.release]
   opt-level = "z"      # Optimize for size
   lto = true           # Link-time optimization
   codegen-units = 1    # Better optimization (slower compile)
   strip = true         # Remove debug symbols
   panic = "abort"      # Smaller binary, no unwinding
   ```

2. Verify no duplicate [profile.release] sections exist.

3. Build the release binary:
   ```bash
   cargo build --release --features gui
   ```

4. Check the binary size:
   ```bash
   ls -lh target/release/contrapunk
   ```
   Target: under 15MB on macOS (typical egui app is 5-12MB).

5. Verify the binary runs:
   ```bash
   ./target/release/contrapunk
   ```
  </action>
  <verify>cargo build --release --features gui && ls -lh target/release/contrapunk</verify>
  <done>Release binary builds successfully with optimizations, size under 15MB</done>
</task>
