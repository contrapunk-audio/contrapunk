**src/humanize/beat_clock.rs:**
- `BeatClock` struct with:
  - `bpm: f64`, `beats_per_bar: u8`, `beat_unit: u8`, `running: bool`
  - `start_time_ms: f64` (abstract time in ms, works for both native and WASM)
  - `beat_position: f64`
  - `prev_beat_position: f64` (for beat crossing detection)
- `BeatClock::new(bpm, beats_per_bar, beat_unit) -> Self`
- `BeatClock::start(&mut self, now_ms: f64)` - sets start_time and running=true
- `BeatClock::stop(&mut self)` - sets running=false
- `BeatClock::tick(&mut self, now_ms: f64) -> f64` - compute beat_position from absolute elapsed: `(elapsed_secs * bpm / 60.0) % beats_per_bar`. Store prev_beat_position before updating. Return beat_position.
- `BeatClock::is_offbeat(&self) -> bool` - fractional part between 0.4 and 0.6
- `BeatClock::beat_crossed(&self) -> Option<u8>` - if floor(prev) != floor(current), return beat number (0-indexed within bar)
- `BeatClock::update_tempo(&mut self, bpm: f64, beats_per_bar: u8, beat_unit: u8)` - update without resetting position
- Use `f64` milliseconds for time (not `Instant`) so it works on both native and WASM. The caller provides `now_ms`.

<task type="auto">
  <name>Task 2: Create Humanizer engine with note transformation logic</name>
  <files>src/humanize/engine.rs</files>
  <action>
Create `src/humanize/engine.rs`:

**Humanizer struct:**
- Fields:
  - `config: HumanizeConfig`
  - `clock: BeatClock`
  - `active_humanization: HashMap<u8, HumanizationRecord>` - maps MIDI note number to the jitter/velocity applied at Note-On, so Note-Off uses same values
- `HumanizationRecord` struct (private): `delay_ms: u16, velocity: wmidi::Velocity, duration_delta_ms: i16`

**Methods:**
- `Humanizer::new(config: HumanizeConfig) -> Self` - init clock from config BPM/time sig
- `Humanizer::config(&self) -> &HumanizeConfig`
- `Humanizer::config_mut(&mut self) -> &mut HumanizeConfig`
- `Humanizer::clock(&self) -> &BeatClock`
- `Humanizer::clock_mut(&mut self) -> &mut BeatClock`
- `Humanizer::tick(&mut self, now_ms: f64)` - ticks the beat clock
- `Humanizer::humanize_note_on(&mut self, note: wmidi::Note, channel: wmidi::Channel, velocity: wmidi::Velocity, port: usize) -> HumanizedNote`:
  - If `!config.enabled`, return unchanged note with delay=0, duration_delta=0
  - Compute velocity: if `velocity_enabled`, add random delta in `[-velocity_variation, +velocity_variation]`, clamp to 1..=127. Use `rand::thread_rng().gen_range()`.
  - Compute jitter: if `jitter_enabled`, `gen_range(jitter_min_ms..=jitter_max_ms)`, else 0
  - Compute swing: if `swing_enabled`, call `compute_swing_delay(&self.clock, config.swing_amount)` — if offbeat, delay = `(60_000.0 / bpm / 2.0) * swing_amount` as u16, else 0
  - Total delay = jitter + swing
  - Compute duration_delta: if `duration_enabled`, `gen_range(0..=duration_variation_ms as i16)` (only positive — extension only)
  - Store `HumanizationRecord { delay_ms, velocity, duration_delta_ms }` in `active_humanization` keyed by note number
  - Return `HumanizedNote { note, channel, velocity: humanized_vel, delay_ms: total_delay, duration_delta_ms, port, is_note_off: false }`

- `Humanizer::humanize_note_off(&mut self, note: wmidi::Note, channel: wmidi::Channel, velocity: wmidi::Velocity, port: usize) -> HumanizedNote`:
  - Look up `active_humanization` for this note number. If found, use stored delay_ms and duration_delta_ms. Remove entry.
  - Total delay for note-off = stored delay_ms + stored duration_delta_ms (so note-off is shifted by same jitter PLUS any extension)
  - If no record found (shouldn't happen but be safe), return unchanged note
  - Return `HumanizedNote { ..., delay_ms: total_delay, is_note_off: true }`

- `Humanizer::update_config(&mut self, config: HumanizeConfig)` - updates config and syncs clock tempo if changed

Use `use rand::Rng;` and `use std::collections::HashMap;`.
