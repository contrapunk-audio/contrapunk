<completed_work>

## Enhancement 1: Enhanced CounterpointState
- Added `VecDeque<i8>` interval history buffer (last 4 intervals)
- Added `VecDeque<MelodicDirection>` for melodic contour tracking (last 3 directions)
- Added harmony range tracking (`harmony_range_low/high`)
- New scoring factors: overused interval penalty (-3), fresh interval bonus (+2), contrary motion bonus (+3), parallel motion penalty (-1), range expansion bonus (+2)
- 12 new tests for the enhanced state

## Enhancement 2: Chained Harmonies
- Modified `HarmonyEngine` to support N voices with `voice_count` field
- Changed single `CounterpointState` to `Vec<CounterpointState>` (one per voice pair)
- Added `with_voices(key, mode, voice_count)` constructor
- Added `set_voice_count()` method
- Updated `harmonize()` to chain harmonies: each derived from previous
- Router now sets voice count based on output count
- Each note goes to its corresponding port: melody->p0, h1->p1, h2->p2, h3->p3
- 6 new tests for chained harmonies

## Enhancement 3: Out-of-Key Handling
- Added chromatic consonant interval constants to `scale.rs`
- Added `is_in_scale()`, `transpose_chromatic()`, `harmonize_smart()` methods
- Added `harmonize_chromatic()` that prefers landing on scale tones
- Updated all modes to use `harmonize_smart()` instead of snap+transpose
- Updated `ContraryMotionState` and `CounterpointState` with chromatic fallbacks
- 5 new tests for out-of-key handling
