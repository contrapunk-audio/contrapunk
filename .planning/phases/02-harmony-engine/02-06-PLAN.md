<task type="checkpoint:human-verify" gate="blocking">
  <what-built>Complete harmony engine with 7 modes, key selection, and MIDI routing integration</what-built>
  <how-to-verify>
Test each harmony mode with MIDI hardware:

1. **Setup:**
   - Connect MIDI input device (e.g., Akai MPK Mini)
   - Connect 2+ MIDI output ports (e.g., IAC Driver buses to DAW)
   - Run: `cargo run`
   - Select input port, output ports

2. **Test Mode 1 (Pass-through):**
   - Select Key: C (default)
   - Select Mode: 1
   - Play notes on input
   - Expected: Notes pass through unchanged, only one voice heard

3. **Test Mode 2 (Diatonic Thirds):**
   - Select Mode: 2
   - Play C, D, E, F, G in C major
   - Expected: Hear thirds above (E, F, G, A, B)
   - Thirds should be diatonic (mix of major/minor)

4. **Test Mode 3 (Diatonic Fourths):**
   - Select Mode: 3
   - Play C, D, E, F, G
   - Expected: Hear fourths above (F, G, A, B, C)

5. **Test Mode 4 (Random Below):**
   - Select Mode: 4
   - Play several notes
   - Expected: Random harmony below each note
   - Should include 2nds sometimes

6. **Test Mode 5 (Random Below No Seconds):**
   - Select Mode: 5
   - Play several notes
   - Expected: Random harmony below, but no close dissonant 2nds

7. **Test Mode 6 (Contrary Motion):**
   - Select Mode: 6
   - Play ascending scale (C, D, E, F, G)
   - Expected: Harmony moves DOWN while melody moves UP
   - Play descending scale
   - Expected: Harmony moves UP while melody moves DOWN

8. **Test Mode 7 (Strict Counterpoint):**
   - Select Mode: 7
   - Play notes
   - Expected: Consonant intervals (3rds, 6ths preferred)
   - No parallel fifths or octaves when moving

9. **Test Key Change:**
   - Restart with Key: G
   - Play G major scale
   - Expected: Harmonies are in G major (includes F#)

10. **Test Note Release:**
    - In any mode, play and release notes
    - Expected: No stuck notes, clean release
    - Test with chords (multiple notes held)

**Pass criteria:**
- All 7 modes produce audibly different results
- Harmonies sound musically appropriate (in key)
- No stuck notes on release
- Key selection affects harmony output
