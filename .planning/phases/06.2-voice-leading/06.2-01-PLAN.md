<task type="auto">
  <name>Task 2: Create voicer algorithm</name>
  <files>src/harmony/voice_leading/voicer.rs</files>
  <action>
Create `voicer.rs` with the core voice assignment algorithms:

- `nearest_voicing(current_note: Note, target_pitch_class: u8) -> Note`: Find the nearest octave placement of target_pitch_class to current_note. Calculate semitone distance up and down, pick shorter. Clamp to 0-127. Use `Note::try_from` with fallback to current_note.

- `find_common_tones(prev_notes: &[Note], new_pitch_classes: &[u8]) -> Vec<(usize, u8)>`: Return indices in new_pitch_classes that share a pitch class with any note in prev_notes. Compare using `% 12`.

- `revoice_chord(prev_voicing: &[Note], new_notes: &[Note], style: &StyleRules, registers: &[VoiceRegister]) -> Vec<Note>`: The main algorithm. Input: previous voicing and new harmony output (both include melody at index 0). Output: re-voiced notes.
  Algorithm:
  1. Keep index 0 (melody) unchanged.
  2. Extract pitch classes from new_notes[1..].
  3. Find common tones between prev_voicing[1..] and new pitch classes. Assign those voices to hold their current note.
  4. For remaining voices, use nearest_voicing from prev_voicing[voice_index] to find closest placement of remaining pitch classes.
  5. Clamp each voice to its register (if registers provided for that index).
  6. Check for voice crossing: if voice i has higher MIDI than voice i-1 (where lower index = higher pitch in SATB), swap assignments.
  7. Score the result using `score_voicing`. If parallel fifths/octaves detected and style penalizes them, try swapping the two offending voices and rescore. Pick better option.

- `score_voicing(prev: &[Note], candidate: &[Note], style: &StyleRules) -> i32`: Score based on: common tone bonus, stepwise bonus (movement <= 2 semitones), leap penalty (per semitone beyond 2), parallel fifths/octaves penalty (check ALL pairs using interval_class). Skip index 0 for movement scoring.

- Include tests:
  - nearest_voicing: C4 with target pitch class E -> E4 (closest)
  - nearest_voicing: C4 with target pitch class B -> B3 (down is closer than up)
  - find_common_tones: [C4, E4, G4] and [E, G, B] -> [(0, E), (1, G)]
  - revoice_chord: C major -> A minor holds C and E, moves G to A
  - score_voicing: stationary voices score higher than leaping voices
