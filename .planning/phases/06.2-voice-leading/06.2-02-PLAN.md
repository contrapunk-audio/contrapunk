  <action>
**suspension.rs:**
- `SuspensionState` struct tracking per-voice suspended notes. Fields: `suspended: Vec<Option<Note>>` (one per harmony voice), `resolved: bool`.
- `SuspensionState::new(voice_count: usize) -> Self`: Initialize with None for each voice.
- `SuspensionState::apply(&mut self, prev: &[Note], current: &mut [Note], style: &StyleRules)`: For styles with `require_suspension_prep = true` (Palestrina): if a voice held a common tone that is now dissonant with the new chord context, keep the old note (suspension) and mark it for resolution. On the NEXT call, resolve suspended notes by stepping down one scale degree. For styles without suspension prep, this is a no-op.
- `SuspensionState::reset(&mut self)`: Clear all suspensions.
- Tests: suspension holds a note, next call resolves it downward.

**processor.rs:**
- `VoiceLeadingProcessor` struct with fields:
  - `enabled: bool` (default false)
  - `style: VoiceLeadingStyle` (default Free)
  - `previous_voicing: Option<Vec<Note>>`
  - `voice_registers: Vec<VoiceRegister>` (assigned based on voice count: 2 voices = [S, A], 3 = [S, A, T], 4 = [S, A, T, B], >4 = repeat pattern)
  - `suspension_state: SuspensionState`
- `VoiceLeadingProcessor::new() -> Self`: Disabled by default, Free style.
- `VoiceLeadingProcessor::process(&mut self, notes: &mut Vec<Note>, scale: &Scale)`: The main method.
  1. If `!self.enabled` or `notes.len() <= 1`, return immediately.
  2. If `previous_voicing` is None (first chord), store current voicing and return (no re-voicing on first chord).
  3. Call `revoice_chord(prev, notes, style.rules(), &voice_registers)` to get re-voiced result.
  4. Apply suspension state if style requires it.
  5. Copy re-voiced notes back into `notes` (indices 1..n only, never touch index 0).
  6. Update `previous_voicing`.
- `set_enabled(&mut self, enabled: bool)`, `set_style(&mut self, style: VoiceLeadingStyle)`, `style(&self) -> VoiceLeadingStyle`, `enabled(&self) -> bool`.
- `reset(&mut self)`: Clear previous_voicing and suspension_state. Called on key/mode/style change.
- `set_voice_count(&mut self, count: usize)`: Rebuild voice_registers based on count.
- Tests: processor disabled = no change, processor re-voices for smooth motion, reset clears state.

**Update mod.rs:** Add `pub mod suspension;` and `pub mod processor;`. Re-export `VoiceLeadingProcessor`.
