Create `suspension.rs` implementing the dissonance handling state machine. Suspensions work on a one-chord-delay principle: when a chord changes, one voice may be held from the previous chord (creating a dissonance), then on the NEXT chord change it resolves stepwise down.

```rust
#[derive(Debug, Clone)]
pub struct SuspensionState {
    /// Which voice index (if any) is currently suspended
    suspended_voice: Option<usize>,
    /// The note being held (from previous chord)
    suspended_note: Option<Note>,
    /// Whether we are in preparation, suspension, or need resolution
    phase: SuspensionPhase,
}

#[derive(Debug, Clone, PartialEq)]
enum SuspensionPhase {
    None,
    /// Voice is being held over (dissonant against new chord)
    Suspended,
    /// Next chord change should resolve this voice stepwise down
    NeedResolution,
}
```

Implement:
- `new() -> Self` — starts in None phase
- `process(&mut self, voicing: &mut Vec<Note>, prev_voicing: Option<&[Note]>, scale: &Scale)` — applies suspension logic:
  - If phase is NeedResolution and suspended_voice is Some(i): resolve voice i by moving it one scale step down. Set phase to None.
  - If phase is None and prev_voicing is Some: check if any voice could form a suspension (was consonant in prev chord, would be dissonant in new chord). If so, hold that voice's note from prev_voicing instead of the revoiced note. Set phase to Suspended. Pick the voice deterministically: highest-indexed voice that qualifies.
  - If phase is Suspended: transition to NeedResolution for next call.
- `reset(&mut self)` — clear all state
- Suspension is only active when the style has `require_suspension_prep: true` (Palestrina). For other styles, `process` is a no-op based on a `enabled: bool` field set at construction.

Add `pub mod suspension;` to voice_leading/mod.rs.

Include tests:
- Suspension holds a note for one chord, then resolves stepwise down
- Non-Palestrina styles skip suspension entirely
- Reset clears suspension state

```rust
pub fn harmonize(&mut self, note: Note) -> Vec<Note> {
    // ... existing harmony generation ...
    // result = [melody, harm1, harm2, harm3]

    // Voice leading post-processing (before octave mode)
    if self.voice_leading.enabled && result.len() > 1 {
        let pitch_classes: Vec<u8> = result[1..].iter()
            .map(|n| u8::from(*n) % 12)
            .collect();
        let revoiced = revoice_chord(
            &pitch_classes,
            self.voice_leading.previous_voicing.as_deref(),
            &self.voice_leading.registers,
            &self.voice_leading.style_rules,
        );
        // Replace harmony notes with revoiced versions
        for (i, note) in revoiced.iter().enumerate() {
            if i + 1 < result.len() {
                result[i + 1] = *note;
            }
        }
        // Apply suspension if style requires it
        self.voice_leading.suspension_state.process(
            &mut result,
            self.voice_leading.previous_voicing.as_deref(),
            &self.scale,
        );
        // Store current voicing for next call
        self.voice_leading.previous_voicing = Some(result.clone());
    }

    // Apply octave mode (existing, runs AFTER voice leading)
    self.apply_octave_mode(&mut result);
    result
}
```

- 4+ voices: Soprano, Alto, Tenor, Bass (extras get Tenor range)
