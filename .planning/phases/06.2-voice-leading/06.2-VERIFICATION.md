#### 2. Palestrina Style Strictness

**Test:** Enable Voice Leading. Select "Palestrina" style. Play melody with 3-4 harmony voices.

**Expected:** 
- Very smooth transitions with stepwise motion preferred

#### 3. Bach Chorale Common Tone Holding

**Test:** Enable Voice Leading. Select "Bach Chorale" style. Play melody that repeats some notes (e.g., C-D-C-E-C).

**Expected:** When chord changes, notes that are common between chords should hold (not jump unnecessarily). Listen for "sticky" notes that don't move.

**Why human:** Audible common tone retention is subtle. Code confirms `common_tone_bonus` in scoring, but human ear validates the musical effect.

#### 4. Jazz Style Relaxed Feel

**Test:** Enable Voice Leading. Select "Jazz" style. Compare to Palestrina/Bach.

**Expected:**
- More leaps allowed (up to full MIDI range)
- Parallel fifths/octaves not hard-rejected (only small penalty)
- More chromatic/angular voice motion acceptable

**Why human:** Comparative style perception requires musical judgment. Code confirms different penalty values, but musical character needs listening.

**Why human:** Cross-style comparison requires human musical judgment. Code confirms distinct `StyleRules`, but audible character needs validation.
