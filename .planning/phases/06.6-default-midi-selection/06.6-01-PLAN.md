<task type="auto">
  <name>Task 1: Create MidiDefaults module with save/load/apply functions</name>
  <files>src/midi_defaults.rs, src/lib.rs</files>
  <action>
Create `src/midi_defaults.rs` with:

1. `MidiDefaults` struct (Serialize, Deserialize, Default, Clone):
   - `input_name: Option<String>` -- saved input device name
   - `output_names: Vec<Option<String>>` -- saved output device names per slot

2. Constants for virtual input persistence:
   - `const VIRTUAL_NOTE_GENERATOR: &str = "__virtual:note_generator";`
   - `const VIRTUAL_COMPUTER_KEYBOARD: &str = "__virtual:computer_keyboard";`
   - `const STORAGE_KEY: &str = "midi_defaults";`

3. `#[cfg(feature = "gui")] pub fn save_midi_defaults(storage: &mut dyn eframe::Storage, defaults: &MidiDefaults)` -- serialize to JSON, call `storage.set_string(STORAGE_KEY, json)`. Mirror the pattern in `src/preset/storage.rs`.

4. `#[cfg(feature = "gui")] pub fn load_midi_defaults(storage: &dyn eframe::Storage) -> MidiDefaults` -- deserialize from storage, `unwrap_or_default()`.

5. `pub fn build_midi_defaults(state: &AppState) -> MidiDefaults` -- build defaults from current state:
   - For input_port: if it's INPUT_NOTE_GENERATOR, store VIRTUAL_NOTE_GENERATOR. If INPUT_COMPUTER_KEYBOARD, store VIRTUAL_COMPUTER_KEYBOARD. Otherwise look up the port name from available_inputs.
   - For output_slots: look up each slot's port name from available_outputs. Store Vec<Option<String>>.

6. `pub fn apply_midi_defaults(state: &mut AppState, defaults: &MidiDefaults)` -- resolve saved names back to indices:
   - For input_name: check virtual constants first (map to INPUT_NOTE_GENERATOR / INPUT_COMPUTER_KEYBOARD). Otherwise find matching name in available_inputs. Falls back to None if not found.
   - For output_names: find matching name in available_outputs per slot. Falls back to None per slot.

Import AppState and INPUT_NOTE_GENERATOR/INPUT_COMPUTER_KEYBOARD from `crate::app`.

Add `pub mod midi_defaults;` to `src/lib.rs`.

  <done>MidiDefaults struct exists with save/load/build/apply functions. Virtual inputs use string constants. All functions compile.</done>

  <action>
Wire the midi_defaults module into ContrapunkApp:

1. Add `use crate::midi_defaults;` at top of app.rs.

2. Add field to ContrapunkApp: `midi_defaults_pending: Option<midi_defaults::MidiDefaults>` -- used for WASM deferred application. Initialize to None in the constructor.

3. In `ContrapunkApp::new()`, after loading custom presets from storage (around line 322-327):
   - Load midi defaults: `let loaded_defaults = _cc.storage.map(|s| midi_defaults::load_midi_defaults(s));`
   - After `app.state.refresh_devices()` (line 330):
     - Native path (`#[cfg(not(target_arch = "wasm32"))]`): if loaded_defaults is Some, call `midi_defaults::apply_midi_defaults(&mut app.state, &defaults)` immediately.
     - WASM path (`#[cfg(target_arch = "wasm32")]`): store in `app.midi_defaults_pending = loaded_defaults;` for deferred application.

4. In the WASM update() block where `midi_initialized` is set to true (around line 891-901), AFTER populating available_inputs and available_outputs:
   - Add: `if let Some(ref defaults) = self.midi_defaults_pending.take() { midi_defaults::apply_midi_defaults(&mut self.state, defaults); }`

5. In `eframe::App::save()` (line 820-822):
   - After the existing preset save line, add:
   ```rust
   let defaults = midi_defaults::build_midi_defaults(&self.state);
   midi_defaults::save_midi_defaults(storage, &defaults);
   ```

This ensures: native applies immediately after refresh_devices(), WASM defers until devices are enumerated, and save() captures current selections on shutdown.
