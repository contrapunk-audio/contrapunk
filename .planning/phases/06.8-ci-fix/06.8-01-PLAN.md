<task type="auto">
  <name>Task 2: Improve deploy workflow caching</name>
  <files>
    .github/workflows/deploy.yml
  </files>
  <action>
    Update .github/workflows/deploy.yml:
    1. Replace manual actions/cache block with Swatinem/rust-cache@v2 (shared-key: wasm)
    2. Add Trunk binary cache using actions/cache@v4 with key: trunk-runner.os-v0.21
    3. Conditionally install Trunk only on cache miss (if: steps.trunk-cache.outputs.cache-hit != 'true')
    4. Keep existing trunk build, copy dist, and flyctl deploy steps unchanged

    Final deploy.yml structure:
    ```yaml
    name: Deploy to Fly.io
    on:
      push:
        branches: [main]
    jobs:
      deploy:
        name: Build WASM & Deploy
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v4
          - name: Install Rust
            uses: dtolnay/rust-toolchain@stable
            with:
              targets: wasm32-unknown-unknown
          - uses: Swatinem/rust-cache@v2
            with:
              shared-key: wasm
          - name: Cache Trunk
            id: trunk-cache
            uses: actions/cache@v4
            with:
              path: ~/.cargo/bin/trunk
              key: trunk-${{ runner.os }}-v0.21
          - name: Install Trunk
            if: steps.trunk-cache.outputs.cache-hit != 'true'
            run: cargo install trunk --locked
          - name: Build WASM
            run: trunk build --release
          - name: Copy dist to deploy
            run: rm -rf deploy/dist && cp -r dist deploy/dist
          - name: Deploy to Fly.io
            uses: superfly/flyctl-actions/setup-flyctl@master
          - name: Run flyctl deploy
            run: cd deploy && flyctl deploy
            env:
              FLY_API_TOKEN: ${{ secrets.FLY_API_TOKEN }}
    ```
  </action>
  <verify>
    grep "rust-cache" .github/workflows/deploy.yml && grep "trunk-cache" .github/workflows/deploy.yml
  </verify>
  <done>
    - deploy.yml uses Swatinem/rust-cache@v2 instead of manual cache
    - Trunk binary cached with version-keyed cache key
    - Trunk install skipped on cache hit
  </done>
</task>

<task type="auto">
  <name>Task 3: Add CI workflow for PRs</name>
  <files>
    .github/workflows/ci.yml (new)
  </files>
  <action>
    Create .github/workflows/ci.yml with:
    - Trigger: pull_request to main, push to main
    - Job "check": cargo check (fast compile validation)
    - Job "test": cargo test (unit tests)
    - Job "wasm-check": cargo check --target wasm32-unknown-unknown (WASM compile check)
    - Each job uses Swatinem/rust-cache@v2 with appropriate shared-key
    - wasm-check job installs wasm32-unknown-unknown target via dtolnay/rust-toolchain

    ```yaml
    name: CI
    on:
      push:
        branches: [main]
      pull_request:
        branches: [main]
    jobs:
      check:
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v4
          - uses: dtolnay/rust-toolchain@stable
          - uses: Swatinem/rust-cache@v2
            with:
              shared-key: native
          - run: cargo check
      test:
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v4
          - uses: dtolnay/rust-toolchain@stable
          - uses: Swatinem/rust-cache@v2
            with:
              shared-key: native
          - run: cargo test
      wasm-check:
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v4
          - uses: dtolnay/rust-toolchain@stable
            with:
              targets: wasm32-unknown-unknown
          - uses: Swatinem/rust-cache@v2
            with:
              shared-key: wasm
          - run: cargo check --target wasm32-unknown-unknown
    ```
  </action>
