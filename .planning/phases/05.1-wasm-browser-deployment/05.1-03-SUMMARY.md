# Phase 5.1 Plan 03: Fly.io Deployment Summary

Contrapunk deployed to Fly.io as a WASM web app served by nginx.

## One-liner

Fly.io deployment with nginx serving WASM dist, HTTPS enforced, human-verified working in Chrome.

## What Was Done

### Task 1: Create deployment config and deploy to Fly.io
Created deployment infrastructure:
- `deploy/nginx.conf` — serves WASM with correct MIME types, gzip compression, SPA routing
- `deploy/Dockerfile` — nginx:alpine container with dist/ copied to html root
- `deploy/fly.toml` — Fly.io config with force_https, auto-stop machines, ewr region

Built production WASM with `trunk build --release`, deployed to Fly.io.

**Bug fix during execution:** Initial deployment rendered nothing — WASM was 64KB stub because Trunk builds the bin target (main.rs), not the lib target (lib.rs). The wasm32 block in main() was just `Ok(())`, so LTO eliminated all egui code. Fixed by moving entry point into main.rs wasm32 block. Also changed release profile: opt-level "s" instead of "z", disabled LTO (wasm-opt v123 incompatible with bulk-memory ops from newer Rust). Redeployed with working 2.7MB binary.

### Task 2: Human verification checkpoint
User verified https://contrapunk.fly.dev/ in browser:
- GUI renders correctly
- Application works in-browser
- User confirmed: "it works well in the browser"

## Deviations from Plan

### Auto-fixed: WASM entry point location
- **Issue:** Trunk builds bin target (main.rs), not lib target (lib.rs)
- **Fix:** Moved WASM entry point from lib.rs into main.rs wasm32 block
- **Impact:** 64KB stub → 2.7MB working binary

### Auto-fixed: Release profile optimization
- **Issue:** wasm-opt v123 can't handle bulk-memory ops from newer Rust with LTO + opt-level "z"
- **Fix:** Changed to opt-level "s", disabled LTO

## Decisions Made

1. **Entry point in main.rs**: Trunk only builds the bin target, so WASM startup must be in main.rs
2. **Release profile**: opt-level "s" with no LTO for wasm-opt compatibility
3. **lib.rs kept but unused**: Still has wasm32 cfg gate, harmless — could be cleaned up later
