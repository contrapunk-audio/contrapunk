<tasks>

<task type="auto">
  <name>Task 1: Create deployment config and deploy to Fly.io</name>
  <files>deploy/Dockerfile, deploy/nginx.conf, deploy/fly.toml</files>
  <action>
1. Create deploy/nginx.conf:
   - Listen on port 80
   - Root /usr/share/nginx/html
   - try_files for SPA routing
   - WASM MIME type: application/wasm
   - gzip on for wasm, js, html, css
   - Cache headers for static assets

2. Create deploy/Dockerfile:
   - FROM nginx:alpine
   - COPY dist/ /usr/share/nginx/html/
   - COPY deploy/nginx.conf /etc/nginx/conf.d/default.conf

3. Create deploy/fly.toml:
   - app = "contrapunk" (user may need to change this if taken)
   - primary_region = "ewr"
   - internal_port = 80
   - force_https = true
   - auto_stop_machines = "stop"
   - auto_start_machines = true
   - min_machines_running = 0

4. Build production WASM: `trunk build --release`
5. Deploy to Fly.io:
   - `cd deploy && fly launch --no-deploy` (if not already created)
   - Copy dist/ into deploy context: `cp -r dist/ deploy/dist/`
   - `cd deploy && fly deploy`
   - Note: user needs `flyctl` installed and authenticated. If auth fails, create a checkpoint.

6. Verify the deployed URL loads and shows the GUI.
  </action>
  <verify>
    `curl -I https://contrapunk.fly.dev` returns 200 with correct content-type.
    Opening the URL in Chrome shows the Contrapunk GUI.
  </verify>
  <done>Contrapunk is live on Fly.io with HTTPS, WASM loads, GUI renders.</done>
</task>
