<task type="auto">
  <name>Task 1: Add WASM dependencies and cfg-gate platform-specific code</name>
  <files>Cargo.toml, src/main.rs, src/router.rs, src/app.rs, src/midi/mod.rs, src/midi/input.rs, src/midi/output.rs, src/midi/ports.rs, src/server/mod.rs, src/server/session.rs</files>
  <action>
1. Update Cargo.toml:
   - Add `wasm` feature: `wasm = ["gui"]`
   - Add target-specific WASM deps under `[target.'cfg(target_arch = "wasm32")'.dependencies]`:
     - wasm-bindgen = "0.2"
     - wasm-bindgen-futures = "0.4"
     - web-sys = { version = "0.3", features = ["Navigator", "Window", "Document"] }
     - js-sys = "0.3"
     - console_error_panic_hook = "0.1"
     - getrandom = { version = "0.2", features = ["js"] }
   - Gate midir: move from [dependencies] to `[target.'cfg(not(target_arch = "wasm32"))'.dependencies]`
   - Gate clap the same way (no CLI in WASM)

2. Gate all std::thread usage in router.rs with `#[cfg(not(target_arch = "wasm32"))]`. For WASM, the router will be replaced with frame-based polling in Plan 02.

3. Gate server module with `#[cfg(not(target_arch = "wasm32"))]` in both mod.rs and wherever it's imported (main.rs).

4. Gate all midir imports in midi/*.rs files with `#[cfg(not(target_arch = "wasm32"))]`. The entire midi module content (input.rs, output.rs, ports.rs) is native-only. Add `#[cfg(not(target_arch = "wasm32"))]` to the module declarations in midi/mod.rs.

5. In app.rs, gate the imports of `std::thread::JoinHandle`, `crate::midi::ports::*`, and `crate::router::spawn_gui_router` with `#[cfg(not(target_arch = "wasm32"))]`. Gate fields and methods that use these types. For WASM, the app will need stub/placeholder implementations that compile — add `#[cfg(target_arch = "wasm32")]` variants that are minimal (empty available_inputs/outputs, no router thread). The full WASM MIDI integration comes in Plan 02.

6. Ensure `cargo check` (native) still passes.
7. Run `rustup target add wasm32-unknown-unknown` and ensure `cargo check --target wasm32-unknown-unknown --features wasm` compiles (may have warnings, but no errors).
  </action>
  <verify>
    `cargo check` passes (native).
    `cargo check --target wasm32-unknown-unknown --features wasm` passes.
    `cargo test` passes (native, existing tests).
  </verify>
  <done>Both native and WASM targets compile without errors. All existing tests pass on native.</done>
</task>
