  <action>
1. Create `src/theme/widgets.rs` with these custom widget functions:

**Ornate Slider** — `pub fn ornate_slider(ui: &mut egui::Ui, label: &str, value: &mut f32, range: RangeInclusive<f32>) -> egui::Response`:
   - Allocate rect with `ui.allocate_exact_size()`, Sense::click_and_drag
   - Draw label text left-aligned above the slider in TEXT_SECONDARY color
   - Draw rail (track): thin horizontal rect in WIDGET_INACTIVE color, rounded corners
   - Draw fill: filled portion from left to value position in COPPER color
   - Draw knob: circle at value position in AMBER color with COPPER_HOVER stroke
   - On hover: knob brightens to GOLD
   - On drag: update value from pointer position, clamp to range
   - Draw value text right-aligned above slider in TEXT_DIM

**Ornate Toggle** — `pub fn ornate_toggle(ui: &mut egui::Ui, label: &str, value: &mut bool) -> egui::Response`:
   - Pill-shaped toggle (rounded rect)
   - OFF: WIDGET_INACTIVE fill, BORDER stroke
   - ON: COPPER fill, GOLD stroke, with circle indicator sliding right
   - Label text to the right

**Decorative Frame** — `pub fn draw_ornate_frame(painter: &egui::Painter, rect: egui::Rect)`:
   - Outer border: 3px BORDER color, 4px rounding
   - Inner border: 1px BORDER color, 3px rounding, 5px inset
   - Corner accents: small filled circles (6px radius) at each corner in CORNER_ACCENT
   - Optional: small gear/cog shapes at corners instead of circles

**Gear/Cog Helper** — `pub fn draw_gear(painter: &egui::Painter, center: egui::Pos2, radius: f32, teeth: usize, angle: f32, color: Color32)`:
   - Draw circle body at center
   - Draw teeth as line segments radiating outward at equal angles, rotated by `angle`
   - 8 teeth by default for small gears, 12 for large

**Section Header** — `pub fn section_header(ui: &mut egui::Ui, text: &str)`:
   - Draws text in GOLD color with a horizontal rule below in BORDER color
   - Used to separate UI sections in Craft tab

2. Add `pub mod widgets;` to `src/theme/mod.rs`.

3. All widget functions use colors from `super::colors::*`. No hardcoded Color32 values.
