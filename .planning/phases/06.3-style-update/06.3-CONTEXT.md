# Phase 6.3: Style Update - Context

**Gathered:** 2026-01-30
**Status:** Ready for planning

<domain>
## Phase Boundary

Modernize GUI appearance with a steampunk/retro-game/Zelda-inspired dark vibrant theme, reorganize the layout into tabbed sections, add musical style presets with character personas, and support custom preset creation/saving/export.

</domain>

<decisions>
## Implementation Decisions

### Visual design direction
- Dark & vibrant aesthetic — deep dark backgrounds with bold, saturated accent colors
- Dark theme only (no light mode toggle)
- Steampunk + retro-game + Legend of Zelda inspired visual identity
- Warm golds, copper/amber tones, gear/cog motifs, rune-like decorative elements
- Animations: both ambient background (gears turning, particles) AND music-reactive elements (respond to MIDI input)
- Animated background behind main UI + ornate decorative frame around the app
- Fully themed custom UI widgets — ornate sliders, gear knobs, rune-style icons (not just recolored egui defaults)

### Musical style presets
- Large preset library — base five (Jazz, Classical, Pop, Baroque, Minimal) plus Lo-fi, Ambient, Gospel, Soul, Metal, Prog, and more
- Each preset named as character persona with genre subtitle (e.g., "The Alchemist — Jazz")
- Presets configure harmony mode, voice leading, humanization, and octave settings as a bundle
- Immediate apply on selection — no preview step
- Built-in presets are read-only (always available as starting points)

### Preset customization & saving
- Two creation paths: "tweak & save-as" from existing preset, or create from scratch
- Unlimited custom preset slots
- Storage: local storage (browser/WASM) or local filesystem (native)
- Export capability available (JSON format)
- Built-in presets cannot be modified or deleted

### Layout & organization
- Reorganized layout (not just restyled)
- Tabbed navigation: Play / Craft / Settings
- Piano keyboard and active notes always visible across all tabs
- **Play tab**: simplified controls — key, mode, MIDI device selection, active preset quick-switch
- **Craft tab**: full parameter editor (harmony, humanization, voice leading params) + preset save/edit/create features
- **Settings tab**: app configuration
- Active preset character shown as icon/avatar next to preset name (subtle, not a large card)
- All three elements (piano, preset character, controls) equally prominent

### Claude's Discretion
- Exact preset selector placement in UI
- Specific character persona names for each built-in preset
- Tab visual design (tab bar style, icons)
- Exact animation implementations within egui capabilities
- Settings tab content organization
- Additional preset styles beyond the discussed list

</decisions>

- Character personas for presets — fits the steampunk/fantasy aesthetic (like a game character select)
- Craft tab as a dedicated workspace for deep parameter tweaking and preset creation
- Play tab kept clean and performance-focused with only essential controls
