<context>
The core issue was that the GSD executor agents generated structurally correct code but visually poor UI. The background layer approach was fundamentally wrong for egui (panels fill over it). The layout used no max-width containers or visual grouping, resulting in tiny controls floating in empty space.

The fix pattern is simple and consistent:
1. Wrap each section in egui::Frame card with WIDGET_BG/BORDER/rounding(8)/margin(16)
2. Center content with max-width container
3. Use section_header() or gold RichText for card titles
4. Use ui.columns() for side-by-side controls

The ornate_slider and ornate_toggle widgets work fine — they just need to be inside cards that give them visual context.
