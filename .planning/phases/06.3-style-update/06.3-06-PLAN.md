<task type="auto">
  <name>Task 1: Add animated background gears and decorative frame</name>
  <files>src/app.rs, src/theme/widgets.rs</files>
  <action>
1. In `update()` of ContrapunkApp, BEFORE any panels:
   - Get `ctx.input(|i| i.time)` for animation timing
   - Get the full screen rect via `ctx.screen_rect()`
   - Use `ctx.layer_painter(egui::LayerId::background())` to paint BEHIND all panels

2. Draw ambient background:
   - 3-5 gears at fixed positions (corners and edges of the screen), rotating slowly using `draw_gear()` with `time * 0.3` (slow) and `time * -0.2` (counter-rotating)
   - Use dim colors (WIDGET_INACTIVE with 60-80 alpha) so gears are subtle background elements
   - Small floating particles: 5-10 small dots drifting slowly upward using sine wave motion. Use `time * 0.5` for vertical drift, `(time * 0.3 + seed).sin() * amplitude` for horizontal wobble. Color: GOLD with 30-50 alpha.

3. Draw decorative frame:
   - Call `draw_ornate_frame(painter, screen_rect.shrink(2.0))` on the background layer
   - Frame is always visible, drawn behind all content

4. Music-reactive elements:
   - Track a `note_activity: f32` field in ContrapunkApp that represents recent MIDI activity (0.0 = silent, 1.0 = active)
   - On each frame: if input_notes or harmony_notes are non-empty, set note_activity = 1.0; otherwise decay: `note_activity *= 0.95`
   - Use note_activity to modulate:
     - Gear rotation speed: base_speed + note_activity * 2.0
     - Gear color brightness: lerp from dim to COPPER based on note_activity
     - Optional glow: draw a larger, semi-transparent circle behind the gear center when note_activity > 0.3
   - Small particle burst on new note events (compare note count frame-to-frame)

5. Request repaint for animations:
   - Use `ctx.request_repaint_after(Duration::from_millis(33))` (30fps) when note_activity > 0.01 or always for ambient gears
   - Do NOT use `ctx.request_repaint()` (that's 60fps continuous, wastes CPU)
  </action>
  <verify>

  </verify>
