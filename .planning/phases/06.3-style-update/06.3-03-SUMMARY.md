# Phase 6.3 Plan 03: Tab Content and Layout Refactor Summary

Refactored app.rs from SidePanel+CentralPanel into tabbed navigation with Play/Craft/Settings tabs and always-visible piano keyboard.

## One-liner

Tabbed UI with Play (performance), Craft (full editor), Settings (devices) tabs and piano in BottomPanel always visible.

## Decisions Made

1. **Tab content as impl methods**: Each tab file adds methods to ContrapunkApp via `impl ContrapunkApp` blocks, keeping access to all fields without parameter threading.
2. **Deferred start/stop**: Play tab sets `pending_start`/`pending_stop` flags; `update()` consumes them before UI rendering to avoid borrow issues with `ctx`.
3. **Borrow-safe preset selection**: Preset names/indices collected into a `Vec<(usize, String, bool)>` before the ComboBox closure to avoid simultaneous immutable+mutable borrows of `preset_manager`.
4. **Piano always visible**: Placed in `TopBottomPanel::bottom` so it renders regardless of active tab.
