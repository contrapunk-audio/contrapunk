# Phase 6.4 Plan 01: ScaleMode & Modal Interchange Summary

**One-liner:** 9-mode ScaleMode enum with modal interchange borrowing from parallel modes, wired into HarmonyEngine

## What Was Done

### Task 1: ScaleMode enum and Scale parameterization
- Added `ScaleMode` enum to config.rs with 9 variants: Ionian, Dorian, Phrygian, Lydian, Mixolydian, Aeolian, Locrian, HarmonicMinor, MelodicMinor
- Each variant has `intervals()` returning correct semitone offsets
- `Scale::new(tonic, mode)` constructor uses mode intervals
- `Scale::major()` convenience wraps `Scale::new(tonic, Ionian)`
- Added `interchange_enabled`, `borrowing_range`, `last_borrowed_from` fields to Scale
- `harmonize_smart()` delegates to `harmonize_with_interchange()` when interchange enabled and note is out-of-key
- Modal interchange searches parallel modes by borrowing_range (1=Aeolian, 5=all church modes)
- Changed `harmonize_smart` from `&self` to `&mut self` to track last_borrowed_from
- Propagated `&mut Scale` through modes.rs and stateful.rs

### Task 2: HarmonyEngine wiring
- Added `scale_mode`, `interchange_enabled`, `borrowing_range`, `last_borrowed_from` fields
- `set_scale_mode()` rebuilds scale and propagates interchange settings
- `set_key()` uses `Scale::new(key, self.scale_mode)` preserving mode
- `set_interchange_enabled()` and `set_borrowing_range()` propagate to Scale
- `harmonize_note_on()` copies `last_borrowed_from` from Scale for UI access
