# Phase 06.4 Plan 03: GUI Integration for Modal Harmony Summary

Scale mode dropdown, modal interchange controls, piano tinting, and roman numeral chord display wired into GUI.

## What Was Done

### Task 1: Scale mode dropdown and interchange controls
- Added `scale_mode`, `interchange_enabled`, `borrowing_range` fields to ContrapunkApp
- Added Scale dropdown (9 modes) next to Key dropdown in Harmony card
- Added Modal Interchange toggle with borrowing range slider (1-5)
- Updated chord display to use `chord_display_with_analysis` showing roman numerals
- Added borrowed-from indicator label in amber when interchange active (WASM)
- Added router sync for scale_mode/interchange/borrowing_range (native)
- Added WASM engine sync each frame
- Updated StylePreset with serde defaults for backward compatibility
- Updated all 11 builtin presets with new fields

### Task 2: Scale tinting and borrowed note highlighting
- Piano keys now show subtle warm/gold tint for in-scale notes
- Borrowed notes (harmony notes when interchange active) highlighted in amber
- Color priority: input > borrowed > harmony > scale tint > default
