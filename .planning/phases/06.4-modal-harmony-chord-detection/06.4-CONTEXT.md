# Phase 6.4: Modal Harmony & Chord Detection - Context

**Gathered:** 2026-01-31
**Status:** Ready for planning

<domain>
## Phase Boundary

Expand the music theory engine with all 7 church modes plus harmonic/melodic minor scales, modal interchange (borrowing from parallel modes) with visual feedback, and comprehensive chord detection (extended chords, slash chords, add chords, roman numeral analysis). The existing harmony modes and UI framework stay unchanged — this phase adds scale awareness and smarter chord recognition.

</domain>

<decisions>
## Implementation Decisions

### Scale/Mode Selection UX
- Separate "Scale" dropdown next to existing "Key" dropdown (e.g., Key: C | Scale: Dorian)
- All 9 modes in one flat list: Ionian, Dorian, Phrygian, Lydian, Mixolydian, Aeolian, Locrian, Harmonic Minor, Melodic Minor
- Scale choice affects ALL harmony modes uniformly (including Pass-through scale pool)
- Default: Ionian (Major) — same as current behavior, no breaking change

### Modal Interchange Behavior
- User toggle to enable/disable modal interchange (when off, use current chromatic fallback)
- Borrowing range slider (1-5): controls how many parallel modes are available for borrowing
  - 1 = only parallel minor
  - 5 = all 9 parallel modes on same root
  - Intermediate steps progressively unlock more modes
- When multiple modes match an out-of-key note, tie-breaking is Claude's discretion (use music theory best practices — closest mode or best consonance)

### Visual Feedback for Borrowing
- Both color highlight AND text label when modal interchange occurs
- Orange/amber color for borrowed/interchange notes on piano keyboard (fits steampunk palette, distinct from white=input, green=harmony, magenta=generator)
- Persistent "borrowed from C Dorian" indicator — stays visible while borrowed note is held/active
- Piano keyboard shows scale tint: light tint on all in-scale keys so the scale shape is always visible

### Chord Naming Conventions
- Context-aware enharmonics: sharps in sharp keys, flats in flat keys (musically correct)
- Full notation: Cadd9/E — show slash chords, add chords, all extensions explicitly
- Ambiguous combinations: show intervals + best guess with '?' (e.g., "C-F# (tritone)?" or "Cmaj7?")
- Roman numeral analysis: show both chord name and function — "Fmaj7 (IVmaj7 in C)"

### Claude's Discretion
- Modal interchange tie-breaking algorithm when multiple parallel modes contain the out-of-key note
- Progressive mode unlocking order for the 1-5 slider (which modes unlock at each step)
- Scale tint color/opacity on piano keys
- Exact chord detection algorithm for extended/altered chords
- Layout placement of the borrowing range slider and interchange toggle

</decisions>

<specifics>
## Specific Ideas

- The borrowing range slider should feel like a "how adventurous" control — conservative at 1, experimental at 5
- Roman numeral analysis is educational — helps users learn theory while playing
- Scale tint on piano makes the app useful as a theory visualization tool even without playing

</specifics>
