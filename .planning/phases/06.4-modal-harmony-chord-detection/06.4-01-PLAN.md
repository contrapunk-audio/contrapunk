<task type="auto">
  <name>Task 1: Add ScaleMode enum and parameterize Scale construction with modal interchange</name>
  <files>src/harmony/config.rs, src/harmony/scale.rs</files>
  <action>
In config.rs, add a ScaleMode enum with these variants (with Serialize, Deserialize, Clone, Copy, Debug, PartialEq, Eq):
- Ionian (default), Dorian, Phrygian, Lydian, Mixolydian, Aeolian, Locrian, HarmonicMinor, MelodicMinor

Add methods:
- `intervals(&self) -> [u8; 7]` returning semitone offsets from tonic:
  - Ionian: [0, 2, 4, 5, 7, 9, 11]
  - Dorian: [0, 2, 3, 5, 7, 9, 10]
  - Phrygian: [0, 1, 3, 5, 7, 8, 10]
  - Lydian: [0, 2, 4, 6, 7, 9, 11]
  - Mixolydian: [0, 2, 4, 5, 7, 9, 10]
  - Aeolian: [0, 2, 3, 5, 7, 8, 10]
  - Locrian: [0, 1, 3, 5, 6, 8, 10]
  - HarmonicMinor: [0, 2, 3, 5, 7, 8, 11]
  - MelodicMinor: [0, 2, 3, 5, 7, 9, 11]
- `all() -> &'static [ScaleMode]` for menu display
- `Display` impl with human-readable names
- `Default` impl returning Ionian

In scale.rs:
- Add `use crate::harmony::config::ScaleMode;`
- Add `mode: ScaleMode` field to the Scale struct
- Add `last_borrowed_from: Option<ScaleMode>` field to the Scale struct (NOT a tuple return — a persistent field). Add getter `pub fn last_borrowed_from(&self) -> Option<ScaleMode>`.
- Add `interchange_enabled: bool` field to Scale struct (default: false). Add setter `pub fn set_interchange_enabled(&mut self, enabled: bool)`.
- Add `borrowing_range: u8` field to Scale struct (default: 3, clamped 1-5). Add setter `pub fn set_borrowing_range(&mut self, range: u8)`.
- Add `pub fn new(tonic: u8, mode: ScaleMode) -> Self` that uses `mode.intervals()` for offsets
- Keep `Scale::major()` as a convenience (calls `Self::new(tonic, ScaleMode::Ionian)`)
- Add `pub fn mode(&self) -> ScaleMode` getter
- Add modal interchange method `pub fn harmonize_with_interchange(&mut self, note: Note, prefer_above: bool) -> Option<Note>`:
  - Uses self.tonic and self.borrowing_range internally
  - borrowing_range 1-5 maps to progressively more parallel modes available:
    1 = [Aeolian], 2 = [Aeolian, Dorian], 3 = [Aeolian, Dorian, Mixolydian],
    4 = [Aeolian, Dorian, Mixolydian, Phrygian], 5 = all 7 church modes
  - For each available mode, create Scale::new(tonic, mode) and check if the note is in THAT scale
  - If found, use that scale's harmonize_smart() to produce the harmony
  - Set `self.last_borrowed_from = Some(borrowed_mode)` when a match is found
  - If no parallel mode contains the note, fall back to existing harmonize_chromatic()
- **CRITICAL WIRING**: Modify `harmonize_smart()` so that when `self.interchange_enabled` is true and the note is out-of-key (not in the current scale), call `self.harmonize_with_interchange(note, prefer_above)` INSTEAD OF `self.harmonize_chromatic(note, prefer_above)`. When interchange is disabled (default), behavior is unchanged — out-of-key notes still go to harmonize_chromatic(). This is the integration point that connects interchange to the existing harmonize pipeline.

Add tests:
- Scale::new with each mode produces correct degree_of results
- Dorian scale: C Dorian should have Eb (degree 2) and Bb (degree 6)
- Modal interchange finds borrowing source for chromatic notes
- harmonize_smart with interchange_enabled=true calls interchange path for out-of-key notes

</task>

<task type="auto">
  <name>Task 2: Wire ScaleMode and modal interchange into HarmonyEngine</name>
  <files>src/harmony/engine.rs</files>
  <action>
In engine.rs:
- Add `scale_mode: ScaleMode` field to HarmonyEngine (default: ScaleMode::Ionian)
- Add `interchange_enabled: bool` field (default: false)
- Add `borrowing_range: u8` field (default: 3, clamped 1-5)
- Add `last_borrowed_from: Option<ScaleMode>` field for UI display

Add public methods:
- `pub fn scale_mode(&self) -> ScaleMode`
- `pub fn set_scale_mode(&mut self, mode: ScaleMode)` — rebuilds scale with `Scale::new(tonic, mode)`, propagates interchange_enabled and borrowing_range to new scale, resets state and active notes
- `pub fn interchange_enabled(&self) -> bool`
- `pub fn set_interchange_enabled(&mut self, enabled: bool)` — sets on self AND calls `self.scale.set_interchange_enabled(enabled)`, clears active notes
- `pub fn borrowing_range(&self) -> u8`
- `pub fn set_borrowing_range(&mut self, range: u8)` — clamp 1-5, sets on self AND calls `self.scale.set_borrowing_range(range)`, clears active notes
- `pub fn last_borrowed_from(&self) -> Option<ScaleMode>` — returns scale's last_borrowed_from

Update `set_key()` to use `Scale::new(key.semitones_from_c(), self.scale_mode)` instead of `Scale::major()`, and propagate interchange_enabled + borrowing_range to the new scale.

Update `with_voices()` to accept ScaleMode or use default Ionian.

The harmonize pipeline does NOT need changes in engine.rs — the wiring is inside Scale::harmonize_smart() (done in Task 1). The engine just needs to:
1. Keep Scale's interchange_enabled and borrowing_range in sync via the setters above
2. After any harmonize call, copy `self.scale.last_borrowed_from()` to `self.last_borrowed_from` for UI access

Update Default impl to include new fields.

Add tests:
- set_scale_mode changes scale behavior (e.g., C Dorian harmonize produces different notes than C Ionian)
- interchange_enabled flag propagates to scale
- set_key preserves scale_mode
