  <action>
Create src/server/ directory with three files:

**config.rs:**
- `ServerConfig` struct with fields: `port: u16` (default 9900), `max_clients: usize` (default 10)
- Implement Default trait

**protocol.rs:**
- `Message` enum with variants:
  - `MidiData(Vec<u8>)` - raw MIDI bytes (type 0x01)
  - `Configure { key: u8, mode: u8, octave_mode: u8, voice_count: u8 }` (type 0x02)
  - `Ack` (type 0x03)
  - `Disconnect` (type 0x04)
  - `Heartbeat` (type 0x05)
- `read_message(stream: &mut impl Read) -> Result<Message>`: reads [u16 BE length][u8 type][payload] using read_exact()
- `write_message(stream: &mut impl Write, msg: &Message) -> Result<()>`: writes length-prefixed message, calls flush()
- `parse_message(buf: &[u8]) -> Result<Message>`: parses type byte + payload into Message
- `serialize_message(msg: &Message) -> Vec<u8>`: serializes Message to type byte + payload

Use anyhow::Result for errors. Use std::io::{Read, Write} traits (NOT TcpStream directly) so protocol is testable.

**mod.rs:**
- `pub mod protocol;`
- `pub mod config;`
- (session and server loop will be added in Plan 02)
