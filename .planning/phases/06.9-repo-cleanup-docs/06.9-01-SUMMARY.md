# Phase 06.9 Plan 01: Consolidate CI/CD Workflows Summary

**One-liner:** Merged deploy.yml into ci.yml as a gated deploy job depending on all checks passing, main-branch-only.

## What Was Done

### Task 1: Merge workflows into unified ci.yml
Added a `deploy` job to `.github/workflows/ci.yml` with:
- `needs: [check, test, wasm-check]` so deploy only runs after all checks pass
- `if: github.event_name == 'push' && github.ref == 'refs/heads/main'` so PRs never trigger deploy
- All original deploy steps preserved (Trunk cache/install, trunk build, flyctl deploy)

### Task 2: Delete deploy.yml
Removed `.github/workflows/deploy.yml` since all its content now lives in ci.yml.
