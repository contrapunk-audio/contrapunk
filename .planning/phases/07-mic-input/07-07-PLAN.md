<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Complete microphone input feature with:
- Audio capture from microphone (native cpal, WASM getUserMedia)
- Real-time YIN pitch detection with ~46ms latency
- Hysteresis-based note tracking (prevents vibrato note flickering)
- Unified IN dropdown with "Mic: Microphone" option
- Harmony engine integration (mic notes harmonized like MIDI input)
- Settings tab with mic controls (profile, thresholds, latency)
- Play tab pitch display (tuner-style note/cents/confidence)
- Level meter showing audio input level
- Cyan piano key coloring for mic-detected notes
  </what-built>
  <how-to-verify>
**Native Build:**
1. Run `cargo run --features gui`
2. In the IN dropdown, select "Mic: Microphone"
3. Select at least one MIDI output device
4. Click Start
5. Sing or play an instrument into your microphone

**Expected Behavior:**
- Level meter should move when you make sound
- Pitch display should show detected note (e.g., "C4 +5¢")
- Confidence bar should be green/yellow when pitch is stable
- Piano keyboard should show cyan key for detected pitch
- Harmony notes should sound on output (if harmony mode is not PassThrough)
- Latency should feel responsive (under 50ms perceived delay)

**Test Cases:**
1. **Volume Gate:** Whisper quietly - should NOT trigger notes until louder
2. **Confidence Gate:** Make noise (not pitched) - should NOT trigger notes
3. **Pitch Accuracy:** Sing "A" (440Hz) - should show A4 with cents near 0
4. **Vibrato:** Sing with vibrato - should stay on ONE note (not flutter)
5. **Note Changes:** Sing different notes - should change cleanly
6. **Profile Switch:** Change to "Fast Playing" profile - should respond faster
7. **Harmony:** Set harmony mode to "Thirds", sing C - should hear C and E

**WASM Build (optional):**
1. Run `trunk serve`
2. Open http://localhost:8080
3. Select "Mic: Microphone" (browser will ask for permission)
4. Repeat tests above

**What to Report:**
- Does pitch detection work? (Yes/No + details)
- Is latency acceptable? (Yes/No + estimate)
- Does harmony output sound correct? (Yes/No + issues)
- Any UI issues? (Yes/No + details)
  </how-to-verify>
  <resume-signal>
Type "approved" if mic input works correctly.
Type issues if problems found (e.g., "pitch jumps octaves randomly", "no sound output", "latency too high").
  </resume-signal>
