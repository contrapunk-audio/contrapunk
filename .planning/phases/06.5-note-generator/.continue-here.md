<decisions_made>
- Port map uses SATB arrangement position, not array index → DAW routing stays fixed regardless of voice_position
- Anchor violations use `continue` (skip entirely) not `hard_rejected` (could be used in fallback) → absolute constraint
- Pre-filtering placements > post-filtering candidates → smaller cartesian product, no invalid candidates generated
- Fallback register range: 18 semitones (~1.5 octaves) from user's note → musical flexibility + voice leading character
- Octave modes check anchor_ok() per-note before shifts → unchanged note if shift crosses anchor (Spread/BassTrebleSplit), skipped duplicate (Mirror)
