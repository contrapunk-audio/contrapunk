# Phase 06.5 Plan 03: Generator UI Controls Summary

Generator control panel with mode selector, chord picker, duration/velocity sliders, and piano click-to-select for note selection.

## What Was Done

### Task 1: Generator control panel in UI
- Added Note Generator card to right column of three-column layout
- Enable toggle controls generator on/off
- Mode selector: HeldNotes, Chord, Arpeggio Up/Down/UpDown, ScaleRunner, RandomDiatonic
- Chord picker (visible only in Chord mode): root note + quality dropdowns resolving to MIDI notes
- Duration slider (0.125-2.0 beats, snapped to 0.125 steps)
- Velocity slider (1-127)
- Selected notes display showing current note names

### Task 2: Piano keyboard click-to-select
- Extended PianoKeyboard widget with `selectable` mode and `selected_notes` set
- Click-to-select enabled when generator is active
- Hit-testing: black keys checked first (they render on top), then white keys
- Clicking toggles note in/out of generator's selected notes
- Magenta highlight color for generator-selected notes
- Toggled notes synced to generator engine via `set_selected_notes()`

## Decisions Made

1. **Magenta for generator-selected keys** - Distinct from blue (input), green (harmony), and cyan (both) to provide clear visual separation.
2. **Chord resolution in octave 4** - Root note C=60 (MIDI standard C4), intervals added from ChordType.
