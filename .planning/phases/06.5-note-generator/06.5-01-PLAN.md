<task type="auto">
  <name>Task 2: Implement NoteGenerator engine</name>
  <files>src/generator/engine.rs</files>
  <action>
Create `NoteGenerator` struct in `engine.rs` with fields:
- `mode: GeneratorMode` (default: HeldNotes)
- `selected_notes: Vec<wmidi::Note>` (notes chosen by user)
- `active_notes: Vec<wmidi::Note>` (currently sounding, need Note-Off)
- `sequence_index: usize` (position in arp/scale sequence)
- `ascending: bool` (for UpDown arp direction)
- `enabled: bool` (whether generator is active)
- `note_duration_beats: f64` (default: 0.5 = eighth note)
- `last_beat_position: f64` (track last tick position)
- `velocity: u8` (default: 100)

Implement:
- `NoteGenerator::new() -> Self` with sensible defaults (enabled=false, velocity=100, note_duration_beats=0.5)
- `tick(&mut self, beat_pos: f64, _bpm: f64) -> Vec<GeneratorEvent>`:
  - Returns empty if !enabled or selected_notes is empty
  - Quantizes to step grid: `current_step = (beat_pos / note_duration_beats).floor()`
  - On new step (current_step != last_step): release all active_notes (NoteOff), then generate new notes based on mode
  - For HeldNotes: all selected_notes play simultaneously
  - For Chord(_): all selected_notes play simultaneously (chord tones pre-resolved by UI)
  - For Arpeggio(dir): pick next note from selected_notes using sequence_index. Up=ascending, Down=descending, UpDown=bounce. Advance sequence_index.
  - For ScaleRunner: advance through selected_notes sequentially (wrapping)
  - For RandomDiatonic: pick random note from selected_notes using `rand::thread_rng()`
  - Update last_beat_position
- `all_notes_off(&mut self) -> Vec<GeneratorEvent>`: send NoteOff for all active_notes, clear active_notes, reset sequence_index
- `set_mode(&mut self, mode: GeneratorMode) -> Vec<GeneratorEvent>`: call all_notes_off() first, then set mode
- `set_selected_notes(&mut self, notes: Vec<wmidi::Note>) -> Vec<GeneratorEvent>`: call all_notes_off() first, then set notes
- Public getters for enabled, mode, selected_notes, velocity, note_duration_beats
- Public setters for enabled (with all_notes_off on disable), velocity, note_duration_beats

Handle beat position wrap-around: if beat_pos < last_beat_position (new bar), treat as a new step. Use `rand` crate (already a dependency) for RandomDiatonic.
  </action>
  <verify>cargo check compiles. cargo test (if any tests exist) passes.</verify>
  <done>NoteGenerator produces correct GeneratorEvents for all 5 modes. all_notes_off() clears state. Mode/note changes release active notes first.</done>
