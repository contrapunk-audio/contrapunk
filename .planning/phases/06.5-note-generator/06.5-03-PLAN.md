  <files>src/ui.rs</files>
  <action>
Add a generator controls section that appears when the Note Generator is selected as input (or when generator is enabled). Place it in the Play tab, in the appropriate column or section near the existing controls.

Controls to add:
1. **Mode selector** (ComboBox): HeldNotes, Chord, Arpeggio Up, Arpeggio Down, Arpeggio Up-Down, Scale Runner, Random Diatonic. When changed, call `generator.set_mode()` and process returned NoteOff events.

2. **Chord picker** (visible only in Chord mode): Two dropdowns:
   - Root note: C, C#, D, D#, E, F, F#, G, G#, A, A#, B
   - Chord quality: Major, Minor, Dim, Aug, Maj7, Min7, Dom7, Dim7, HalfDim7
   When either changes: resolve chord to concrete wmidi::Note values (root in octave 4, where C4 = MIDI 60; e.g., C Major = MIDI notes 60, 64, 67, computed as `60 + root_offset + interval`), call `generator.set_selected_notes()`.

3. **Note duration** (Slider): Range 0.125 to 2.0 beats, step 0.125. Labels: "1/32", "1/16", "1/8", "1/4", "1/2", "1 bar". Update `generator.note_duration_beats`.

4. **Velocity** (Slider): Range 1 to 127. Update `generator.velocity`.

5. **Selected notes display**: Show currently selected notes as text (e.g., "C4 E4 G4").

When mode changes require clearing or updating selected_notes, always process the returned GeneratorEvent vectors (send note-offs through the harmony engine).
  </action>
