# Phase 10.1: Guitar Reliability — Research

**Researched:** 2026-07-11
**Confidence:** High for repository defects; corpus-specific for detector targets

## Architecture

- Core runtime detector: `crates/contrapunk-audio/src/guitar_input.rs`.
- Tauri capture: `src-tauri/src/guitar_bridge.rs`; currently deinterleaves into a new `Vec`, locks `GuitarInput`, synchronizes config, runs DSP, and sends events from the cpal callback.
- Plugin: `plugin/src/lib.rs`; guitar DSP already runs in `MusicWorker` behind bounded `ringbuf` queues.
- Browser: `wasm/src/lib.rs` and `ui/src/lib/audio/guitarCapture.ts`; Web Audio blocks are posted to browser-main-thread WASM processing.
- Calibration: persisted `GuitarCalibrationProfile` in Tauri plus a separate runtime `GuitarCalibration` in `GuitarInput`.

## Root Causes to Fix Before Tuning

1. First-note correction compares against `current_note`, so it cannot correct the first pitch candidate's octave/harmonic.
2. Sustain code calls `push_slide_cents(cents_from_base)` before `slide_history_prev_cents()`, making the previous value equal to the current value and defeating rapid-jump detection.
3. Vibrato rate assumes one analysis frame per `buffer_size`; analysis actually advances every `hop_size`.
4. Every bend path emits both `PitchBend` and `MidiPitchBend`; Tauri serializes both to identical MIDI pitch-bend bytes.
5. `config_mut()` allows `buffer_size` and `sample_rate` changes while fixed ring/scratch/single-cycle state retains old dimensions.
6. Tauri cpal callback allocates a mono `Vec`, takes mutexes, clones analysis data internally, executes Goertzel/McLeod work, and uses unbounded mpsc sends.

## Minimal Implementation Strategy

- Add one corpus integration test using `hound` as a dev dependency; explicit holdout file avoids a hidden/random split.
- Add a safe whole-config replacement method that returns cleanup events and reconstructs structural state.
- Emit one canonical `PitchBend` event from core and convert to raw MIDI only at adapters.
- Read slide history before writing the current frame; use `hop_size / sample_rate` for vibrato.
- Improve first-note selection with candidate scoring over fundamental/subharmonic candidates from the current analysis window, then tune only against the development partition.
- Reuse the plugin's proven `ringbuf` pattern for Tauri: preallocated interleaved-to-mono queue, worker-owned detector, bounded output queues, explicit overflow cleanup.
- Keep one persisted calibration model. If full unification is too invasive for this release, remove misleading claims and label the existing tuning/noise workflow **Tune Guitar**.

## Evidence Update — 2026-07-18

Authoritative papers/docs and a proven open-source implementation support the following constraints:

- YIN and McLeod Pitch Method require periodic evidence; a 1024-sample window contains only ~1.76 E2 cycles at 48 kHz. Do not globally enlarge the window before fixing onset/attack control flow.
- aubio's note tracker separates onset arming from later pitch maturation and tolerates transient-rich onset frames. For a latency follow-up, latch accepted onset independently of same-frame pitch and keep Attack alive across isolated missing-pitch frames until the existing timeout.
- MIREX treats doubled onsets as false positives. Preserve the joint RMS-slope + spectral-flux articulation gate and do not treat pitch jumps alone as re-plucks.
- MIDI Pitch Bend is channel-wide and persists. Matching NoteOff and bend centering are required; explicitly establishing intended bend/center before a reused-channel NoteOn remains the safest future hardening.
- JACK and PortAudio prohibit allocation, mutexes, sleeps, I/O, and detector DSP in the real-time callback. A preallocated SPSC queue is the established bridge. Queue capacity was tightened from one second to 100 ms so bounded capacity is also a bounded stale-audio budget.

Observed development ablations:

- Sustain RMS ratios 1.5 and 2.0 did not reduce the six retrigger files.
- A 150 ms cooldown shifted duplicate timing but did not reduce the file rate.
- Tracking whether Attack came from an unarticulated pitch jump and suppressing consensus that returned to the active pitch reduced retriggers from 6/108 (5.6%) to 3/108 (2.8%).
- The fixed 75 ms attack minimum was retained. A 20/30/40 ms development-only sweep is deferred until onset latching/dropout tolerance lands; sealed holdout must be run only after selection.
