# Phase 10.1: Guitar Reliability — Context

**Gathered:** 2026-07-11
**Status:** Complete — automated gates passed; manual release smoke is tracked separately

<domain>
## Phase Boundary

Improve the existing shipping guitar pipeline as far as the checked-in 138-file labeled corpus supports. The product claim is limited to clean, monophonic, standard-tuned six-string guitar. This phase does not add polyphonic detection, chord/double-stop support, alternate tunings, bass, extended-range instruments, or broad microphone claims.
</domain>

<decisions>
## Locked Decisions

- Evaluate the actual `GuitarInput` used by the product, not a separate research detector.
- Keep a fixed development/holdout split; tune only against development and report holdout separately.
- Corpus gates certify this corpus only, not guitar input in general.
- Required gates: >=95% exact first-note accuracy, <5% isolated recordings with false retriggers, 100% matching NoteOff cleanup, deterministic repeated output, no crashes/stuck notes, and faster-than-real-time processing.
- Fix confirmed correctness defects before threshold tuning.
- Tauri's cpal callback may deinterleave and enqueue only; `GuitarInput` belongs to a worker.
- Calibration language must match behavior. Use **Tune Guitar** until persisted measurements genuinely calibrate the detector.
- Preserve guitar input on Tauri, WASM/browser, and plugin surfaces; do not claim ordinary Logic guitar-track input while the AU remains an `aumi` MIDI processor.
- Do not stage or alter unrelated Elixir/Golem work.
</decisions>

<specifics>
## Known Evidence

- Corpus: `ui/static/samples/by_class/`, 138 mono 48 kHz 16-bit WAV files, one per string/fret label.
- Audited baseline: 16/138 exact first detections, 32/138 eventual correct detections, 85.5% files with multiple NoteOns.
- Confirmed defects: first-note octave correction lacks history; legato reads its previous cents after pushing the current value; vibrato uses analysis-window duration instead of hop duration; core emits two representations of each bend; structural config changes can replace `buffer_size` without rebuilding buffers; Tauri callback allocates and locks while running DSP.
- Calibration is split between `GuitarCalibrationProfile` and `GuitarCalibration`; the persisted profile only partially influences DSP.
</specifics>

<deferred>
## Deferred

- Chords, double-stops, polyphony.
- Alternate tunings, bass, seven/eight-string instruments.
- Broad acoustic/microphone/noisy-room claims.
- Heavy browser DSP migration to AudioWorklet WASM execution.
- Logic AU audio input until the wrapper is registered and validated as an audio effect/instrument with input.
</deferred>
