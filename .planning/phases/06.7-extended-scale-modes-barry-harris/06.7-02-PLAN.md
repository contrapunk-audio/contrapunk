<objective>
Add Barry Harris harmony mode that implements the 6th diminished movement rules: move by 2 scale degrees in the 8-note scale so chord tones (even degrees 0,2,4,6) map to chord tones and passing tones (odd degrees 1,3,5,7) map to passing tones.

Purpose: Barry Harris movement rules are the musical reason for the 8-note scale. Without this mode, the scales are just data without their intended harmonic function.

Output: New HarmonyMode::BarryHarris variant, barry_harris mode function in modes.rs, engine wiring.
</objective>

1. In config.rs, add `BarryHarris` variant to `HarmonyMode` enum (Mode 8). Update `number()`, `all()`, `description()` methods. Description: "Barry Harris (6th dim movement)".

2. In modes.rs, add `barry_harris(note: Note, scale: &mut Scale) -> Vec<Note>` function:
   - Get the note's degree in the current scale via `scale.degree_of(note)`
   - If note is not in scale, snap to nearest scale tone first
   - Move by +2 scale degrees (this is the BH rule: skip one scale degree to preserve chord-tone/passing-tone parity)
   - Use `scale.harmonize_smart(note, 2, true)` to get the harmony note
   - Return `vec![note, harmony]` or `vec![note]` if out of range

3. Also add `barry_harris_directed(note: Note, scale: &mut Scale, above: bool) -> Vec<Note>` following the same directed pattern as other modes (for voice position support). Must accept `(Note, &mut Scale, bool)` and return `Vec<Note>` — matching the exact signature pattern used by `diatonic_thirds_directed` and called in `engine.rs::harmonize_single_directed`.

Ensure both functions match the engine.rs calling convention:
- `barry_harris(note, scale)` matches `harmonize_single()` call pattern: `modes::barry_harris(note, &mut self.scale)`
- `barry_harris_directed(note, scale, above)` matches `harmonize_single_directed()` call pattern: `modes::barry_harris_directed(note, &mut self.scale, above)`

Note: The movement rule is simple — it's just diatonic thirds in an 8-note scale. The magic is that in a Barry Harris scale, moving by 2 degrees preserves chord-tone/passing-tone parity because the scale has 8 notes (even number). This is identical to `diatonic_thirds_directed` but the musical meaning differs. However, implement it as a separate function for clarity and to allow future BH-specific behavior (e.g., different fallback for non-BH scales).
