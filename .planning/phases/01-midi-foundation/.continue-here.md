<decisions_made>

- Port to Rust for performance and single-binary distribution (no Python runtime)
- Use egui/eframe for GUI (immediate mode, good for real-time apps, cross-platform)
- Use midir crate for MIDI (cross-platform, well-maintained)
- Drop audio-to-MIDI feature (reduces complexity, removes heavy dependencies)
- Drop algorithmic melody generation (scope reduction for v1, focus on live performance)
- All 7 harmony modes will be ported (forward, thirds, fourths, random diatonic, no-seconds, contrary motion, strict counterpoint)

</decisions_made>
