<task type="auto">
  <name>Task 3: Implement quantized lifecycle and bounded capture</name>
  <action>Implement `press`, `clear`, live capture, and transport-discontinuity handling. Running arm starts at the next downbeat. Stopped arm requests transport reset/play and starts after exactly one complete bar. A press while Armed cancels. A press while Recording requests close at the next downbeat. Playing stops immediately; Stopped resumes from the next downbeat. Empty takes return to Empty. Ignore malformed/unmatched releases. Bound a take to 256 beats and 16,384 events; request closure at the next bar when either ceiling is reached (`ponytail:` comment names these ceilings and says to make them configurable only if real sessions hit them).</action>
  <verify><automated>cargo test -p contrapunk-companion --lib loops::tests</automated></verify>
</task>

<task type="auto">
  <name>Task 4: Close ownership at the boundary</name>
  <action>Track pressed `(channel,note)` counts and sustain per channel while recording. At close, append one matching boundary NoteOff per outstanding attack and CC64-up for every down pedal. Boundary cleanup is separate from ordinary `[0,length)` events so wrap ordering is always end releases and pedal-up before offset-zero attacks.</action>
  <verify><automated>cargo test -p contrapunk-companion --lib loops::tests</automated></verify>
</task>

<task type="auto">
  <name>Task 5: Implement exact windowed replay</name>
  <action>Schedule from half-open absolute beat windows, not floating-point equality or `BeatCrossing`. Preserve capture order for equal offsets. Emit all due events exactly once across fine, coarse, delayed, boundary-crossing, and multi-cycle windows. Repeating the same endpoint emits nothing. A transport discontinuity discards Armed/Recording takes, stops retained playback, and requests targeted cleanup for the adapter.</action>
  <verify><automated>cargo test -p contrapunk-companion --lib loops::tests && cargo test -p contrapunk-transport --lib</automated></verify>
