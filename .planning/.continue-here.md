## Critical anti-patterns from this session

| Pattern | Severity | Prevention |
|---|---|---|
| Splitting on first ` (` to strip chord analysis | advisory | Use `lastIndexOf(' (')` + suffix regex check; preserves `(no 5)` partial chords |
| Auto-starting transport from a panel's `onMount` | blocking | Panels persist via localStorage; mount-time effects must be idempotent across reload — require explicit user gesture for irreversible actions |
| Pasting PATs in chat | blocking | Set secrets via `gh secret set ... < /dev/stdin`; never echo the value; rotate immediately if exposed |
| Implicit `auto` grid columns with content-driven width | blocking | Always `grid-template-columns: minmax(0, 1fr)` (or explicit) on full-viewport grids — child `nowrap` text otherwise widens column past viewport |
