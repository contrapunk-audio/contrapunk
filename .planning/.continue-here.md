## Voice input — full plan for v1.4 follow-up

**Reusable from guitar pipeline (~80%):**
- `crates/contrapunk-audio/src/detectors.rs` — McLeod pitch detector handles vocal F0 well

**New for voice (~20%):**

| Concern | Solution | LOC estimate |
|---|---|---|
| Vibrato pitch jitter | 5-7 sample centered median filter on F0 stream | ~30 LOC |
| Voiced/unvoiced detection (skip breath/sibilance) | Spectral flatness + harmonic-to-noise ratio (HNR) from FFT | ~50 LOC |
| Vocal range constraint | Per-register pitch clamping (S 220-1000Hz, A 175-700, T 130-525, B 80-330) | ~10 LOC config + clamp |
| Latency budget | Smaller hop size (128 vs 256 for guitar) | Config change, +CPU |
| Formant interference | Optional pre-emphasis filter (high-shelf +6dB @ 1kHz) | One-tap biquad, ~10 LOC |

**Libraries:**
- Pitch: already shipped (`pitch_detection` crate, McLeod)
- Onset: already shipped (spectral flux in `onset.rs`)
- Median filter: `medians` crate (~10kb) or hand-roll
- HNR: own impl from FFT, straightforward

**Estimate:** ~1 day focused work if guitar pipeline reused cleanly.
