## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention |
|---------|-------------|----------|------------|
| Cross-viewport scope leak | Mobile-targeted CSS (scroll-snap, scrollytelling section heights, SVG attributes) was applied without `@media` gating, breaking desktop layout. Repeatedly. | blocking | Every CSS change scoped to mobile MUST be wrapped in `@media (max-width: 768px)` (or 600px) before commit. Run desktop check after every change. |
| Iterating on a guess | Spent ~6 rounds at 90%+ context iterating on the fretboard mobile height without diagnosing the actual SVG attributes. Each guess made it worse. | blocking | Diagnose before fixing. Curl rendered HTML, inspect attributes, identify what's actually constraining size. |
| Shared embed component edits | `vendor/contrapunk/ui/src/lib/embed/Fretboard.svelte` and `Piano.svelte` are vendored from the contrapunk submodule. Editing the canonical source affects BOTH the website embed AND the desktop app. | advisory | When editing shared embed components, scope responsive logic to the website wrapper (`src/components/embed/Contrapunk*.svelte`) instead of the shared file. |

## Critical Anti-Patterns (do NOT repeat these)

- **Mobile-only changes leaking to desktop**: every CSS change scoped to phone viewports MUST be wrapped in `@media (max-width: 768px)` (or 600px). Verify desktop layout after every change.
- **Iterating on guesses without diagnosis**: when something breaks visually, curl the rendered HTML and inspect what's there before guessing at fixes. The fretboard fix needed inspection of the SVG attributes, not rapid CSS guessing.
- **Editing shared embed components without scoping**: `vendor/contrapunk/ui/src/lib/embed/*.svelte` files are mirrored from the contrapunk submodule. Edits propagate to both website AND desktop app. Prefer scoping responsive logic to the website-side wrappers.
