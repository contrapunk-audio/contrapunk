## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Allocating on the audio thread | new FX/DSP must pre-allocate buffers at construction, never mid-stream | advisory | Wrap audio callback in `assert_no_alloc::assert_no_alloc(|| {…})` in debug builds; CI runs one block of audio in debug per commit |
| Naming the source synth project in derived docs | The ELIXIR design doc was derived from external open-source synth source; user-locked invariant is "never document this provenance" | advisory | `grep -in -E "vital|tytel|matt[ '\"]"` on any derived doc before commit |
| Reusing src/fx/ inside elixir-core | Option A locked: keep Elixir self-contained; revisit as Option B (extract to contrapunk-fx workspace crate) only post A-Cut | advisory | Don't add `contrapunk` as a dep on `elixir-core`; check Cargo.toml before adding any FX dep |
| Committing rigor.yaml | Pre-existing untracked file; not part of Elixir work; explicitly excluded from every commit | advisory | `git reset HEAD rigor.yaml` after `git add -A` |
