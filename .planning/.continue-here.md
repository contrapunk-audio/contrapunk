<decisions_made>

Major architectural pivots this session:
- Pattern programmer removed — companion's true shape is capture-and-replay (looper), not rhythmic-mask
- State machine architecture: Lane trait + WorldState + 3-phase orchestration (Sense → Mutate → Decide)
- Audio graph (DAG) replaces linear chain — supports parallel sources, sub-buses, sidechaining
- Plugin support multi-format (CLAP/VST3/AU/LV2) via `PluginNode` + `PluginInstance` trait — NOT `ClapInstrument` (plugins can be effects)
- Sidechaining first-class via typed ports + `SidechainSense` Node
- Rig saving as first-class feature (versioned JSON, migration framework, native FS + WASM IndexedDB)
- Elixir wavetable synth (Serum-class) replaces BasicSynth long-term — own phase track E0-E12 parallel to Companion
- BeatMachine = Logic Pro Drummer-style (not basic step sequencer): presets, X/Y intensity, auto-fills, internal Rust drum sampler
- Three-thread arch: audio (RT lock-free) / router (companion) / main (Tauri/UI)
- Standardized `Node::params() -> &dyn ParamStore`
- v1.1.0 'Fela FRIDAY' release deleted (zero-asset placeholder), re-tagged as 'Kondo KITT'
