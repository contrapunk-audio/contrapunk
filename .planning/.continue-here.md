### VoiceCard data-shape contract

Each card binds to one canon voice OR one counterpoint config. The data shape:

```ts
type VoiceCardData = {
  index: number;           // 0..N for canon voices, or special index for counterpoint
  type: 'melody' | 'canon' | 'counterpoint';
  // Canon-only:
  transposeDegrees?: number;       // engine.canonVoices[i].transpose_degrees
  delayBeats?: number;             // engine.canonVoices[i].delay_beats
  timeRatio?: number;              // engine.canonVoices[i].time_ratio
  // Counterpoint-only:
  species?: 'Species1' | 'Species2' | 'Species3' | 'Species4';
  // Common:
  holdMode: HoldMode | null;       // null = inherit lane → global
  output: VoiceOutputTarget;       // engine.voiceOutputs[i]
  // Live indicator (v2):
  isFiring?: boolean;              // derived from engine.canonNotes/counterpointNotes
};
```

Selectors in `VoiceGenerationChain.svelte`:
```ts
const voices = $derived(() => {
  const cards: VoiceCardData[] = [];
  // Melody = voice position 0 (the player's seat in the harmony stack)
  cards.push({
    index: 0,
    type: 'melody',
    holdMode: null,
    output: engine.voiceOutputs[engine.voicePosition],
  });
  // Canon voices
  engine.canonVoices.forEach((v, i) => {
    cards.push({
      index: i + 1,
      type: 'canon',
      transposeDegrees: v.transpose_degrees,
      delayBeats: v.delay_beats,
      timeRatio: v.time_ratio ?? 1.0,
      holdMode: v.hold_mode ?? null,
      output: engine.voiceOutputs[i + 1],
    });
  });
  // Counterpoint lane (if enabled)
  if (engine.counterpointEnabled) {
    cards.push({
      index: cards.length,
      type: 'counterpoint',
      species: engine.counterpointSpecies,
      holdMode: engine.counterpointLaneHoldMode,
      output: engine.voiceOutputs[cards.length] ?? { kind: 'Synth' },
    });
  }
  return cards;
});
```

### SVG arrow rendering approach (locked)

```svelte
<!-- VoiceGenerationChain.svelte -->
<div class="chain">
  <div class="input-node" bind:this={inputEl}>...</div>
  <div class="voice-row">
    {#each voices as v}
      <div bind:this={cardEls[v.index]}><VoiceCard {v} /></div>
    {/each}
  </div>
  <svg class="arrows" {viewBox}>
    {#each voices as v}
      <path d={arrowPath(inputEl, cardEls[v.index])} />
    {/each}
  </svg>
</div>
```

`arrowPath()` returns an SVG cubic Bezier from input node's bottom-center to card's top-center:
```ts
function arrowPath(from: HTMLElement, to: HTMLElement): string {
  const f = from.getBoundingClientRect();
  const t = to.getBoundingClientRect();
  const fx = f.left + f.width / 2;
  const fy = f.bottom;
  const tx = t.left + t.width / 2;
  const ty = t.top;
  const midY = (fy + ty) / 2;
  return `M ${fx} ${fy} C ${fx} ${midY}, ${tx} ${midY}, ${tx} ${ty}`;
}
```

**Reactivity**: recompute on window resize and on `voices` length change. Use a `ResizeObserver` on the chain container.

**Performance**: up to 8 voices typical, ~16 worst-case. ~10 SVG paths is trivial — no virtualization needed.

**Risk**: getBoundingClientRect is layout-dependent, fires on mount. Use `tick()` from Svelte after mount before reading positions. If positions are still wrong (e.g. fonts loading), guard with a one-frame `requestAnimationFrame` delay before first arrow render.

### Calibration port: full call graph

Source flow (from `examples/guitar_calibrate.rs`):
1. User clicks Calibrate → Tauri command `start_guitar_calibration(device, channel)` (NEW; previous one was deleted in `fe83b54`)
2. Command spawns blocking task that:
   a. Opens cpal stream on selected device + channel
   b. Captures noise floor (1 sec silence)
   c. For each of 6 strings, prompts user to play open string (UI shows "Play open E2 now..."), captures 2 sec, computes peak amplitude + spectral profile
   d. Optionally captures fretted samples for inharmonicity
   e. Builds `GuitarCalibrationProfile` (real one from `crates/contrapunk-audio/src/guitar.rs:155`)
   f. Serializes to `app_data_dir/guitar_calibration_profile.json`
   g. Returns profile to UI
3. New function `load_calibration_profile(app: &AppHandle) -> Result<Option<GuitarCalibrationProfile>, String>` at startup
4. `GuitarBridge::start` (in `src-tauri/src/guitar_bridge.rs`) — currently constructs `GuitarInputConfig` with defaults. Add: if calibration exists, call `AudioNormalizer::from_profile(profile)` and inject into the config. Pass through to `GuitarInput::new(config)`.
